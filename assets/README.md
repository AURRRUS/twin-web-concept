# Изображения и референсы

Сюда загружайте утверждённые логотипы, изображения, скриншоты и визуальные референсы Twin.

Материалы пока не загружены. Для загрузки откройте эту папку → Add file → Upload files → Commit changes.

Используйте понятные имена файлов. Указывайте в ТЗ, какие изображения являются финальными, а какие служат только референсами.
