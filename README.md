# Twin Web Concept

Стартовый репозиторий для работы над веб-концептом Twin в Codex.

## Текущее состояние

Репозиторий подготовлен. Исходные документы, изображения и код проекта ещё не перенесены. Приложения и команды запуска пока нет.

## Как добавить наработки из GPT

1. Скачайте актуальные файлы из нужного чата GPT.
2. На главной странице репозитория выберите Add file → Upload files.
3. Загрузите документы и код, сохраняя исходную структуру кода. ZIP с кодом предварительно распакуйте.
4. Нажмите Commit changes — сохранить изменения.

Документы и ТЗ размещайте в docs/, изображения и референсы — в assets/. Готовый код переносите со всеми его конфигурационными файлами. Не загружайте пароли, токены и файлы .env.

## Первая задача в Codex

Выберите этот репозиторий при создании облачной среды. Затем напишите:

> Изучи все файлы проекта и AGENTS.md. Объясни, что уже готово и чего не хватает. Если есть код — подготовь запуск и проверь его. Если есть только ТЗ — предложи минимальный план реализации. Не выдумывай отсутствующие требования. В конце объясни простым языком, как посмотреть результат.

## Рабочий цикл

Задача → изменения Codex → проверка результата → сохранение изменений в GitHub. Публикация сайта настраивается отдельно.
