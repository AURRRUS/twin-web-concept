# Подключение предоставленных шрифтов — desktop 0.6

Владелец прислал «Шрифт RFDewi.rar» и «Шрифт inter tight.rar» в ответ на запрос гарнитур. Это новое основание внедрения выше прежнего временного Manrope и исторических OPEN_DECISION. Архивы распакованы и изучены; выбраны обычные RF Dewi, без самовольной подмены на Condensed/Expanded/Extended.

Назначение: RF Dewi Regular 400 для основных заголовков, настоящие Semibold 600 и Bold 700 для соответствующих акцентов; Inter Tight Variable 100–900 для основного текста, кнопок, форм, навигации и UI. RF Dewi не является variable: промежуточные веса заголовков заменены на имеющиеся. Синтез начертаний отключён. Растровый логотип и текст внутри исторических изображений не перерисовывались.

Файлы пользователя преобразованы в WOFF2 без смены геометрии глифов и без отсечения кириллицы. Использованы fontTools и Brotli как разовая подготовка; runtime Python не нужен. Источник/контрольные суммы/размеры — FONT_ASSETS_2026-10-20.json. Сохранены copyright/notice из таблиц имён: src/assets/fonts/SOURCE_NOTICES.txt. Файлы обслуживаются сайтом, внешний CDN не требуется. Astro/Vite добавляет hash к URL, критические Regular/Inter preload, font-display swap. Депенденси Manrope и его CSS удалены.

Проверено: кириллические cmap, реальные веса RF 400/600/700, ось Inter wght 100–900; typecheck/build и 10 тестов. В Chromium все четыре FontFace имеют status loaded, computed h1 RF Dewi, body Inter Tight. На 1280×800, 1440×1000, 1920×1000 нет overflow и наложения интро/навигации второго блока; три принудительные строки hero сохранены. Снимки первого экрана, страницы, карты, диалога, демо и сцен пересозданы браузерными тестами. Публичный прогон проверяет обе реально загруженные гарнитуры, а не только CSS font-family.

Публикация — существующий Pages, manifest desktop-0.6. Подключение гарнитур выполнено по последнему предоставлению владельца; отдельное утверждение корпоративного брендбука целиком этим не заявляется. Увеличенные плавно сменяемые сцены 0.5 сохранены.
