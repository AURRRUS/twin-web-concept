# Twin — FINAL R2, читать перед реализацией

Единый актуальный пакет от 2026-10-23 для AURRRUS/twin-web-concept. Заменяет прежнюю редакцию этого пакета; старые противоречащие задания не исполнять. Это ТЗ для Twin by TALENT, не для ПИН.

1. Сначала выполнить раздел 0 в 01_IMPLEMENTATION_SPEC.md: зафиксировать и отправить резервную исходную версию, сохранить ссылку на прежнюю публикацию, создать отдельную рабочую ветку.
2. Прочитать 01_IMPLEMENTATION_SPEC.md полностью: все прежние разделы сохранены, уточнены Journey и резервное сохранение.
3. Подключить контент Journey по JOURNEY_STATES.json. Порядок: Проект → Корпус → Этаж → Лот. Технический этап и его рекламный заголовок — разные поля.
4. Проверить девять изображений по ASSET_MANIFEST.json. Все четыре правых изображения Journey включены явно: project.png, corpus.png, floor.png, lot.png. План этажа — третьим, изображение апартамента — четвёртым. Левое вертикальное изображение и hero сохранить из репозитория.
5. Выполнить остальные правки: первый экран; центральная модель состава; четыре канала со стопкой карточек; позднее однократное раскрытие треугольника без пересечений; типографика, reveal и якоря.
6. Проверить реальное поведение и сборку. После успешных проверок сразу опубликовать штатным способом. Согласование скриншотов не требуется.

PROMPT_FOR_CODEX.txt также передан владельцу текстом. Детализация реализации — в 01_IMPLEMENTATION_SPEC.md. В архиве девять исходников: четыре канала продаж, четыре состояния Journey, одна прозрачная центральная модель. Старые файлы не удалять до проверки всех ссылок; замена изображений не должна ломать другие компоненты.

Новых файлов шрифтов нет: используются реальные брендовые файлы действующего репозитория. Не подменять RF Dewi Expanded Black 900 файлом Bold или системным шрифтом.

Центральная модель относится только к составу и его диалогу. Общий media key core и треугольник этой картинкой не заменять.

Три механики различаются: Journey повторяемый и обратимый; стопка каналов повторяемая и обратимая; треугольник однократный. Не объединять их в общий once-reveal.

Этот пакет не означает, что изменения уже реализованы, резервная ветка уже создана или новая версия опубликована. Эти действия выполняет разработчик, подтверждая их результатами.
