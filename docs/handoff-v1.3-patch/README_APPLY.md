# Как применить v1.3 к архиву v1.2

Это небольшой документальный patch без повторной загрузки изображений.

1. Распакуйте существующий TWIN_WEBSITE_HANDOFF_v1_2_2026-10-18.zip.
2. Скопируйте содержимое OVERLAY в корневую папку комплекта, согласившись на замену совпадающих файлов. Копировать нужно содержимое OVERLAY, а не саму папку.
3. Удалите старую копию `00_STANDARDS/TALENT_WEBSITE_DEVELOPMENT_MASTER_v1_2026-10-18.md`; вместо неё используется v1_1. В источниках проекта замените старый master новым файлом, не храните оба как действующие.
4. Старые PACKAGE_FILES.json/PACKAGE_VALIDATION.json относятся только к v1.2. После применения patch используйте проверку ниже: старую проверку не выдавайте за проверку сборки v1.3.
5. По желанию запустите `python3 VERIFY_PATCH.py /абсолютный/путь/к/корню/комплекта`. Скрипт сверяет изменённые файлы и базовые ассеты с исходным v1.2, не тестирует сайт.
6. Передайте разработчику START_HERE_TWIN.md; первое задание — TW-00.

Альтернатива для работы только в чате: приложите обновлённый master и `OVERLAY/01_SPECS/TWIN_DELIVERY_PIPELINE.md` вместе с исходным v1.2; явно укажите приоритет обновления.
