## Принятый рабочий вариант

Белая главная, рабочий логотип G, сквозная архитектурная история. Карта состава: коммерческий цифровой двойник в центре; клиентские инструменты, виртуальный отдел продаж, контентная система, управление и аналитика, интеграции, коммерческие модули вокруг. Коммерческие модули — расширение. Карта открывает модалки, позже их можно заменить отдельными страницами по тем же IDs.

Блок реализации: 3 месяца, в среднем5млн ₽, качество через демонстрацию. Цифры получены от владельца и не равны фиксированным условиям любой конфигурации. Нет утверждения о самом быстром решении на всём рынке.

## Работа с изображениями

Файлы фонов намеренно без подписей, номеров, рамок выбора и логотипов. «Подписать» выполнено именами файлов и реестром: изображение остаётся чистым для вёрстки. PNG с `_ALPHA` имеют настоящий прозрачный канал. Для офисного фото и интерьера лучше ставить заголовок в отдельном белом поле, а не поверх пёстрых деталей. Для hero допускается дополнительный белый CSS-градиент слева, текст всегда DOM. Для полного слайда16:9 портретный фасад ставить левой колонкой, не растягивать.

Иллюстрации созданы AI для демонстрационного проекта. Они не являются архитектурной документацией, реальным внедрением Twin, рабочим интерфейсом, 3D-файлом или документальной съёмкой. Единая художественная семья не означает точного геометрического совпадения между кадрами. Для точного пролёта/морфинга требуются согласованные исходники. Форматы исходных генераций сохранены без искусственного upscale; реальные размеры перечислены в manifest. На слайды1920×1080 можно размещать пропорционально; это не превращает исходник в native4K.

## Что есть и чего ещё нет

Есть: две спецификации, content config, шесть фоновых/предметных PNG, два вспомогательных SVG, два PNG логотипа, три новых изображения каналов, четыре точные SVG UI-иллюстрации, локальный интерактивный каталог и24 PNG состояний. Визуальные опоры и снимки исходных текстов сохранены.

Пока нет: целиком реализованной главной и её motion, backend формы, точного векторного production-master G, набора6 отдельных изометрических предметов для каждого пункта карты и согласованной послойной3D/video-сцены. UI-экраны предоставлены как review prototype: их можно использовать в разработке, но это не настоящий подключённый продукт. Это перечислено для планирования следующего прохода. Системная карта в `03_REFERENCES` — эталон компоновки, не набор готовых интерактивных слоёв.

Архив не меняет корпоративные документы или навыки; ранние source snapshots сохранены для происхождения. При конфликте применяются новые спецификации и последние решения владельца.
