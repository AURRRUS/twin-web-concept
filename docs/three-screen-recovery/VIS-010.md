# VIS-010 — архитектурная видеосцена Twin

2026-11-13. Owner: пользователь. Утверждены концепт портала и прозрачные кулисы; поручена реализация.

Рабочая ссылка: https://aurrrus.github.io/twin-web-concept/v2/motion-preview/
Редактируемые файлы: v2/enhancements/portal-scene-v2.js и portal-scene-v2.css. Архитектура: architecture-wings.webp (RGBA, прозрачный центр), исходный generated PNG сохранён как изображение чата. Левый/правый слой используют один атлас с clip-path и независимыми transform.

Реализовано: графитовая глубина, heading DOM RF Dewi Expanded, удаление мелких подписей, scroll-driven translateZ видео, разъезд кулис, pin115svh, пауза просмотра, reverse, explicit Play и native controls после запуска, pause при уходе. Mobile/short viewport и reduced motion имеют отдельные CSS ветки; их полная визуальная матрица пока не подтверждена.

QA: JS syntax PASS, WebP центр RGBA(0,0,0,0), обе маски загружаются в Chrome1363×936. Выявлено смещение origin после hydration Journey — исправлено чтением актуальной позиции в paint и ResizeObserver opening. Файлы версионированы для исключения старого browser cache. Не присваивать автоматический visual PASS или одобрение владельца.

Первые два экрана этим пакетом не перепроектировались. Основной /v2/ пока прежний, новый портал в motion-preview. Не собирать поверх старой work/twin-v2: её TSX отстаёт от опубликованного runtime. Editable recovery runtime живёт в twin-preview/v2; миграция обратно в полный Astro source остаётся отдельной технической задачей.
