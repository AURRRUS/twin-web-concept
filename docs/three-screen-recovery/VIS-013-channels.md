# VIS-013 — Каналы продаж

Дата: 2026-11-13.

Убраны повторные заголовки каналов, верхняя подпись, повторное вступление и стрелки. Оставлены единый селектор из четырёх каналов, актуальное описание и стопка изображений. Шрифт заголовка наследует TV2OpeningExpanded. Добавлены sticky-сцена и последовательное переключение через React по прогрессу скролла; ручной выбор перемещает к соответствующему этапу. Обратный скролл поддерживается. На узких/низких экранах и reduced-motion фиксация отключена. Диагональная бронзовая линия связывает сцену с блоком качеств; финансовые claims не менялись.

Проверено в Chrome 1363×936: фиксация top=0, четыре сценария по скроллу, синхронное описание, ручной выбор первого и последнего, выход к качествам и обратный вход. JS syntax check passed. Мобильный UX в этой итерации не проверен в браузере. Исправлена тесная типографика заголовка, добавлено обновление CSS-кэша.

Реализация сохраняет опубликованный runtime. Основная /v2/ не изменена; кандидат /v2/motion-preview/.
