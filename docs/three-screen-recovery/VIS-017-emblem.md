# VIS-017 — Объёмный знак Twin

Решение владельца: заменить центральную иллюстрацию на объёмный знак с эффектным появлением. Исходник — текущий mark-light.webp из опубликованного набора, без перерисовки/зеркалирования. Глубина — восемь слоёв того же ассета, общая перспектива, единый световой проход. Это CSS-объём, не новый 3D мастер логотипа.

Live-модуль emblem-v1.js. Desktop >=1100×700, без reduced-motion: 180svh track, sticky100svh; normalized progress p=0..1 маппится в t=0..4. p0..0.62: Y54→0, rotateX12→0, rotateY−32→0, scale.73→1; opacity .25→1 кp.22. p.48..86: один мягкий блик; далее hold. Обратный скролл вычисляет те же состояния из абсолютного p. Никаких таймеров/autoloop/перехвата wheel. При скрытой вкладке driver не рисует; scroll/resize/visibility инициируют rAF. На мобильном, низком экране и reduced-motion — финальное статическое состояние без удлинения track.

Смысловой текст и CTA остаются DOM. Оригинальные сроки/бюджет/формулировки не меняются. Header/logo первого экрана сохранены. Каналы: font clamp19..25px, selected700, бронзовая линия и мягкая подложка, без дополнительных мелких подписей. Фон qualities full-width независимо от r4-wrap; нижняя светотень каналов также100vw.

Файлы: ReferencePage.emblem-v1.js, emblem-v1.css/js, соответствующий SSR. Preview /v2/motion-preview/; основная /v2/ не меняется. MP4 не заказан и не производится.
