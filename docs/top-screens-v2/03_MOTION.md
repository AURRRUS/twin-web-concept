# Scroll-сценарий: каскад, не одновременный fade
Носитель: живой сайт, DOM+CSS, 3 состояния, без автоплея/видео/звука. Пользователь управляет обычным скроллом. requestAnimationFrame только для обновления отображения по progress, не автономной прокрутки.

## Общая шкала
Для desktop sticky-секции стартовая высота host=300svh; sticky panel=100svh; путь=hostHeight−panelHeight. P=clamp((scrollY−hostTop)/путь,0,1). Sticky только при достаточных размерах из основного ТЗ. Не привязываться к числу событий wheel или времени.
0.00–0.20: полностью читаем состояние1.
0.20–0.40: переход1→2, локальное q=(P−0.20)/0.20.
0.40–0.60: полностью читаем состояние2.
0.60–0.80: переход2→3, локальное q=(P−0.60)/0.20.
0.80–1.00: полностью читаем состояние3, затем естественный выход из sticky.

## Каждый переход, q от0 до1
| Интервал | Заголовок | Медиа | Пояснение |
|---|---|---|---|
| 0.00–0.15 | старый opacity1→0, Y0→−8px | старое полностью | старое полностью |
| 0.15–0.40 | новый opacity0→1, Y12→0px | старое полностью | старое полностью |
| 0.40–0.80 | новый полностью | crossfade старое→новое, новое Y12→0px | старое opacity1→0 кq=.70 |
| 0.80–1.00 | новый полностью | новое полностью | новое opacity0→1, Y6→0px |
Таким образом новый заголовок целиком появился до начала смены картинки. На краткой фазе новый заголовок над старым медиа — намеренный каскад. Зоны не меняют размеров. Не оставлять пустой весь правый блок между состояниями. easing=smoothstep(t)=t*t*(3−2*t) внутри каждого интервала, все значения определяются текущим P без очереди таймеров.
Фасад и позиции колонок не меняются. Параллакс фасада в этой версии не требуется. Никаких вращений, bounce, крупных zoom или штор, закрывающих UI.
Навигация: целевые P=.10/.50/.90; обычный scrollTo smooth для перехода, без перехвата wheel/touch. Активная кнопка переходит к новой сцене приq=.80, когда её медиа целиком видно. При большом скачке P сразу корректная сцена, без проигрывания пропущенных анимаций. При обратном скролле точный обратный ход по той же функции.
Остановка скролла останавливает переход; никакого setTimeout на500ms, который доделывает другую сцену после пользователя. Допустимо сглаживание самого прогресса только если не нарушает детерминированную проверку; предпочтителен прямой mapping.

## Доступность и fallback
Кнопки нативные, Tab/Enter/Space работают, focus виден. На inactive слоях нет фокуса и дублирующего чтения; не делать aria-live announcer на каждом кадре. Текст смысловых состояний остаётся доступен без JS через статический HTML.
Reduced-motion: последовательные статические сцены без sticky-прокрутки и трансформаций, либо прямой выбор без анимации с доступом ко всем трём состояниям. Для этой задачи использовать первый вариант, единый с mobile.
Resize/смена ориентации: пересчитать геометрию, не сбросить пользователя в начало страницы; при отключении sticky не оставлять300svh пустоты. При скрытой вкладке прекратить обновления, после возврата восстановить из фактического scrollY. Ошибка изображения не делает пустой блок: видимая подпись и устойчивый размер, никаких ложных утверждений о загруженном медиа.
