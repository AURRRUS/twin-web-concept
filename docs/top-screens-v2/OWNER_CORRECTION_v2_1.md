# Уточнение владельца — v2.1

21.10.2026 владелец явно подтвердил исправление назначения двух исходников:

- Чистую панораму `Вид побережье.png` использовать для hero.
- Террасу с запечённым интерфейсом `Роскошный апартамент с видом на море.png` использовать для сцены «Пространство».

Это уточнение имеет приоритет над соответствующими строками исходных `manifest.json`, `02_ASSET_MAP.md` и `ASSET_INDEX.html` v2. Исходный manifest сохранён без подмены, поэтому его SHA-256 по-прежнему проверяет оригинальные файлы, а фактическое назначение производных записано отдельно в `IMPLEMENTED_ASSETS.json`.

Полного отдельного архива v2.1 в этом сообщении не приложено. Реализация использует прочитанный пакет v2 с этой явно подтверждённой поправкой; другие неизвестные изменения v2.1 не предполагаются.
