# Twin: первые два экрана — исполнимое ТЗ v2
Дата: 21.10.2026. Это новый пакет конкретной задачи, не реконструкция прежнего полного архива.

## Читать и выполнять в этом порядке
1. Прочитать AGENTS.md и README актуального репозитория. Затем этот файл и 01_TASK_SPEC.md целиком.
2. Открыть ASSET_INDEX.html: глазами сверить все пять изображений. Прочитать 02_ASSET_MAP.md и manifest.json. Не назначать изображения по одним названиям файлов.
3. Прочитать 03_MOTION.md, 04_ACCEPTANCE.md, 05_CURRENT_REVIEW.md и 06_BRAND_AND_FONTS.md.
4. Определить актуальную исходную ветку, запустить исходный сайт, снять baseline на размерах из приёмки. Не начинать с пустого main и не откатывать чужую работу.
5. Реализовать первый экран, сетку и второй экран. Проверить desktop, mobile, клавиатуру и reduced-motion. Затем проверить /demo/ на регрессии.
6. Сдать работающий код, ссылку/команду локального просмотра, скриншоты до/после, таблицу измерений и краткий отчёт по приёмке. Не ограничиваться планом или текстовым советом.

## Приоритет
Последние явные решения владельца → данное ТЗ по первым двум экранам → актуальные документы Twin → старые комментарии кода. Старый CSS-комментарий про три строки и горизонтальную навигацию больше не задание. Архивные исходники reference/source — доказательство состояния, не файлы для слепой замены.

## Граница задачи
Основные изменения на https://aurrrus.github.io/twin-web-concept/ . Ссылка владельца https://aurrrus.github.io/twin-web-concept/demo/ ведёт на отдельный демонстрационный интерфейс: там проверить общую сетку, шапку, адаптив и сохранность выбора. Не заменять демо маркетинговым hero и не перестраивать весь viewer.
Не менять без задачи нижние секции, контент продукта, CRM/backend, логотип и набор функций. Деплой этим пакетом не поручен; подготовить проверяемый результат.

Все пять исходных PNG приложены без изменения байтов. Этот пакет сам содержит инструкции, привязку медиа и технические исходники для сверки. Контекст прошлых чатов не требуется. Отсутствующие материалы и ограничения указаны явно.
