# Бренд и шрифты: без выдуманных канонов
Источник: действующий профиль Twin by TALENT v1.6 от17.10.2026, прочитан при подготовке; актуальный код репозитория.
Twin и ПИН — разные бренды. Профиль Twin прямо запрещает автоматически переносить RF Dewi и фирменный код ПИН и не утверждает точные гарнитуры Twin этим обновлением. Поэтому нельзя объявлять «RF Dewi Extended — канон Twin» по памяти.
При этом текущая реализация уже использует локальный RF Dewi для H1/H2/H3 и Inter Tight для тела/UI. В рамках задачи исправления вёрстки сохранить фактическую проектную типографику; сверить с актуальными документами Twin в docs/handoff и явно зафиксировать найденное основание. Если там есть более позднее прямое утверждение конкретной гарнитуры — применить его и указать документ. Не подменять Arial/Montserrat/Manrope по собственному вкусу.
В reference/fonts приложены реальные4 WOFF2 из src/assets/fonts исходного commit, не заменители из CDN. font-metadata.json содержит внутренние названия файлов. Это резерв текущей реализации, не утверждение лицензионного/брендового статуса и не новая дизайн-система. Не распространять эти файлы отдельно от задачи.
Проверить фактическое начертание/кириллицу и Network/Font Loading API/Rendered Fonts. Название CSS family не доказывает внутреннее семейство файла. Не синтезировать bold и не объявлять обычный RF Dewi Extended без подтверждения metadata.
Сохранить существующий полный логотип Twin by TALENT из репозитория, с by, пропорциями и текущим утверждённым разворотом; не перерисовывать/зеркалить. В новых пяти картинках нет нового master-логотипа и нет новых шрифтов.
Сохранить светлую базу, графит и дозированную бронзу текущего сайта. Не переносить кристалл, палитру или кнопки ПИН. Старый слоган «Из проекта — в выбор. Из выбора — в продажу.» отменён, в публичный интерфейс не возвращать.

Фактически проверено при сборке: внутренние семейства трёх rf-dewi-*.woff2 — RF Dewi (не Extended), inter-tight-variable.woff2 — Inter Tight. Все четыре содержат кириллицу использованного заголовка. Это проверка файлов, не доказательство их отрисовки в браузере будущей реализации.
