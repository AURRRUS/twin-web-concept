# Контракт подключения Twin — проект версии 0.1

## I00. Граница контракта
Ниже целевой интерфейс нашего адаптера, не описание существующего API Twin. Транспорт выбирается после обследования viewer: iframe/postMessage, SDK или отдельное приложение. Автоматический выбор iframe и обещание WebGL не допускаются.

## I01. Методы адаптера
| Метод | Вход | Результат |
|---|---|---|
| mount | container, projectId, initialSelection | ready/capabilities либо типизированная ошибка |
| select | selection, requestId | подтверждённый выбор либо unsupported/not_found |
| setView | view, requestId | подтверждение либо unsupported |
| subscribe | callback | функция отписки |
| destroy | — | сняты listeners, освобождены ресурсы |

Capabilities: selectLot, selectFloor, setView, selectionEvents, pause. Каждый флаг подтверждается реализацией адаптера, не названием продукта. Недоступный control скрыт/объяснён; не эмулировать успешную команду.

## I02. Конверт сообщения
Для команд/событий: schemaVersion, type, messageId, requestId (если ответ), sessionId, projectId, payload. Время события фиксируется принимающей системой; время viewer — дополнительное поле. Версия 0.1 — предложение контракта. Примеры типов: viewer.ready, selection.changed, viewer.error, viewer.disposed; команды select и setView.

## I03. Валидация и циклы
**INT-01.** Проверять версию, тип и схему payload, projectId, принадлежность ID каталогу и текущую сессию. Запоздалое событие после destroy игнорируется.
**INT-02.** requestId связывает подтверждение команды; messageId защищает от повторной обработки. Последний пользовательский выбор имеет приоритет над устаревшим ответом.
**INT-03.** При обновлении store помечать source=site/viewer/url. Эхо подтверждения не запускает ту же команду повторно. Ограничить частоту событий камеры; не отправлять каждый кадр в аналитику.
**INT-04.** Нет подтверждения — показывать pending/error; выбранный лот не считать применённым в viewer. Каталог может сохранять свой выбор с понятным состоянием связи.

## I04. При iframe
Проверять точный event.origin и event.source, отправлять на разрешённый targetOrigin, без wildcard. Настроить минимальные sandbox/permissions и CSP по проверенным потребностям. Не передавать секреты в URL/DOM или публичный JSON. Авторизованный embed при необходимости получает короткую серверную сессию. Условия frame-ancestors и авторизации проверить на стенде.

## I05. URL и завершение
В URL только публичные ID и вид, без персональных данных/токенов. Конкретное кодирование определяет router. History не заполняется каждым движением камеры. При закрытии очищать сессию и подписки; при повторном входе выполнить новый handshake. Несовместимая major-версия ведёт к резервному каталогу.

## I06. Приёмка транспорта
Подключение считается проверенным после настоящего handshake, выбора и обратного события на целевых origin/устройствах. Mock adapter подтверждает интерфейс оболочки, но не работоспособность Twin. Результаты и неподдержанные capabilities фиксируются отдельно.
