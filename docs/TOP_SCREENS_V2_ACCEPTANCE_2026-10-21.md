## Реализовано

- Hero: чистая панорама; ровно две смысловые строки H1 от 1280 px; три от 951 до 1279 px, естественные переносы ниже. Тексты, точка и маршруты CTA сохранены. Шрифт H1 44–64 px на контрольных desktop-ширинах; без scaleX.
- Общий `content-container` у шапки, hero и сцены. Gutter вычисляется через `cqw` корневого layout-контейнера, поэтому не включает полосу прокрутки. C≤1408 px, поля 20 px на телефоне и 32 px на 601–950. Компенсация прозрачного поля исходного логотипа выведена из alpha bounds и описана в CSS, не переносится на текст.
- Старые hero/journey-переопределения удалены из `site.css`; новые правила собраны в `top-screens.css`. Вторая сцена — один grid `3fr / minmax(150px,1.5fr) / 7.5fr`, gap24. Фасад занимает левую колонку с явным вылетом только влево. Вертикальная навигация — среднюю, заголовок/медиа/пояснение — правую. Справа медиа заканчивается на R.
- Три H2 и три пояснения из ТЗ. Заголовки занимают общую grid-ячейку, высота определяется максимальным реальным текстом. Поэтому смена opacity не двигает рамку.
- Чистая функция `journeyFrame` отображает P непосредственно в фазы заголовка, медиа и пояснения по разделу 03. При P=.28/.68 новый заголовок уже opacity1, следующее изображение ещё opacity0, предыдущее — opacity1. Нет очереди таймеров, параллакса фасада или автопрокрутки; один rAF на изменение. Кнопки ведут к P=.10/.50/.90 нативным smooth scroll.
- Три изображения UI показаны целиком через contain, без tint/mix-blend-mode и второго комплекта нарисованных controls. DOM-подпись о демонстрационных данных присутствует. Оптимизированные WebP лежат отдельно в `media/top-v2/`; старые медиа нижних секций и viewer сохранены. У hero responsive-набор с достаточной плотностью для cover на высоком телефоне; сцены декодируются при приближении блока.
- До 1280 px, при высоте ниже 800 и с reduced-motion — три последовательные пары H2+медиа+пояснение. Фасад mobile 320 px. Вариант без JS содержит все три состояния. Сбой изображения сохраняет размер и показывает ошибку.
- RF Dewi и Inter Tight не заменены. Это сохранение фактической типографики по поручению и 06_BRAND_AND_FONTS, не заявление о новом брендовом каноне. Исходники соответствуют прежнему `FONT_ASSETS_2026-10-20.json`; Chromium Rendered Fonts подтвердил собственные webfonts и ненулевые glyphCount для кириллицы заголовка и абзаца.

## Локальный просмотр

```sh
git switch codex/twin-top-screens-v2
npm ci
npm run dev -- --port 4327
```

Адрес на локальном компьютере: `http://localhost:4327/`; демо — `/demo`. Для просмотра production base path:

```sh
npm run build:preview
TWIN_BASE_PATH=/twin-web-concept npm run preview -- --port 4326
```

Адрес: `http://localhost:4326/twin-web-concept/`. В облачной среде loopback не является публичной ссылкой. Запускайте на свободном порту.

Публикация в этой задаче не выполнялась в соответствии с границей приложенного пакета. Safari, реальные телефоны и полевые показатели производительности не проверены. Приёмка владельцем не подменяется успешными тестами. Полного отдельного архива v2.1 не было: реализован предоставленный v2 с явно подтверждённой поправкой ассетов.
