# Сравнительная сборка Journey

База — актуальная f4a1c17 поверх опубликованной45e9135, без отката к указанной ранее c9fa164. До правок на GitHub сохранены backup/before-journey-comparison-2026-10-24 и backup/pages-before-journey-comparison-2026-10-24. Текущий Journey не редактировался; неизменность его исходников, движка, общих стилей, hero, каналов, треугольника, JSON и четырёх изображений подтверждена SHA-256 в preserved-files.json.

Порядок: Hero → панель сравнения → исходный Journey → Два масштаба → Одно окно в проект → Четыре главы → существующие Product/Composition/Channels/Delivery/Contact. Служебные подписи и возвраты стоят вне сцен. Победитель не выбран.

Два масштаба: около21% фасад,16% навигация,63% правая область с поправкой на поля/gap. Пояснение есть только у активного пункта, его высота резервируется во всех четырёх строках. Текст строго в правой колонке над визуалом. Одно окно: архитектурная полоса11%, горизонтальный маршрут, независимые резервированные title/body слоты, большое неподвижное окно и счётчик. Геометрия для1366×700 рассчитана отдельно; H2 в компактном режиме30px, на1440 примерно38/36px, на1920 —46/44px. Это не масштабирование всей панели.

Оба host473svh/panel100svh. Применяется существующий journeyFrameV3 и его reading stops/непрозрачные листы. Единственный адаптер делает текстовые маски комплементарными, чтобы исключить пустоту; маркер меняется на8% перехода, заголовок начинается на15%, описание30%, лист45%. Сами листы/scale/Y из движка не переопределены второй timeline. Прямой passive scroll→один RAF, без хвоста после остановки, таймеров, wheel/touch interception или snap. Каждый экземпляр имеет собственные refs, состояние, DOM IDs, обработчики и готовность. Общее содержимое неизменяемое; ни один глобальный querySelector не управляет первым Journey вместо клона.

Четыре главы: обычный поток, min-height90svh для спокойного чтения на desktop. Проект — заголовок слева/описание справа/широкая картинка; Корпус — текст слева/изображение справа; Этаж — компактный текст/более широкое поле плана; Лот — изображение слева/текст справа. Узкий sticky-указатель ограничен этой секцией, выбирает реально наиболее видимую главу. Отдельные локальные появления600ms с масками и задержками0/90/180ms, без длинного pin-трека. На mobile четыре обычные главы.

На узких экранах и при reduced-motion первые два варианта показывают компактный переключатель, текст и один полный визуал, без473svh. При недостаточной высоте используется тот же switch-режим. Без JS — четыре полноценные статические статьи. Никаких изображений не генерировали, не перерисовывали и не кадрировали; все продуктовые картинки contain, фасады cover. Встроенные растровые кнопки не являются внешними интерактивными элементами. Разворот открывает исходник в уникальном native dialog с Escape, удержанием и возвратом фокуса.

Шрифты — существующие реальные Black900/Semibold600; описания Inter Tight450/1.55/.015em. Проверены computed styles и custom PostScript fonts в Chrome. Исходные тексты заголовков/описаний/навигационных пояснений из FINAL R2, вторая часть бронзовая, NBSP не даёт коротким словам висеть отдельно. Между span есть реальные пробелы.

Проверено: typecheck/build, полная серия38 Playwright PASS (30 прежних +8 сравнительных),10001 математический кадр без пустых текстовых фаз/альфа-смешения и с комплементарными масками. На1920×1080/1440×900/1366×700 — все состояния/переходы/паузы/обратный ход/повторный вход/четыре навигационных пункта и главы;390×844 и reduced-motion — переключатели/поток. Проверены уникальность ID, клавиатура,12 разворотов оригиналов, прямые якоря после гидрации, исходный Journey на семи размерах, каналы и последовательный треугольник под добавленными секциями. Снимки просмотрены. Итог публикации — ONLINE.md.

Ограничения: три заявленных макета в сообщении отсутствовали; композиции выполнены по текстовому ТЗ. Chromium с эмуляцией размеров, без физического trackpad, Safari/iOS и реальных устройств. Мобильная часть — база сравнительных вариантов, не новый общий mobile redesign. Неподключённые интеграции и честные статусы сохранены.
