20.10.2026 (Москва). Linux, Node 24, системный Chromium через Playwright. Текущая реализация продолжает существующий Astro/React/TypeScript проект. Описание изменений: VISUAL_DELIVERY.md; исходный аудит прототипа: DESKTOP_REVIEW_2026-10-20.md.

Подтверждены TypeScript, статическая сборка двух маршрутов и 10 браузерных сценариев без пропусков. Машинный отчёт: artifacts/test-results.json. Проверяются загрузка медиа, отсутствие горизонтального overflow при 1280/1440/1920, семь диалогов, Escape/Back/Forward/фокус, четыре канала и клавиатура, перенос выбора и сброс родителей, невалидные ID, форма без POST, ошибка медиа, reduced-motion и отсутствие JS. Дополнительно проверяются реальная загрузка Manrope Variable, смена трёх архитектурных состояний в обе стороны и runtime reduced-motion; чужой проект не сохраняет дочерние ID.

Снимки фактического приложения: first-screen, desktop-1440/1920, composition-desktop, delivery-desktop, component-dialog, demo-desktop, journey-project/space/lot. Перед снимком треугольника ожидается окончание анимации рёбер. Снимки не заменяют работающий сайт и не служат утверждением идентичности эталону.

Публичная проверка вынесена отдельно: scripts/verify-online.mjs ожидает соответствия build-version.json исходному commit, затем проверяет страницу HTTP 200, шрифт, диалог, канал, перенос выбора на /demo, видимые изображения и ошибки браузера. Итоговый наблюдаемый статус — artifacts/online-verification.json. Из локальной облачной среды GitHub Pages возвращал CONNECT 403; поэтому предусмотрен запуск браузерной проверки на GitHub-hosted runner с сохранением наблюдений в исходную ветку. До получения PASS онлайн-проверка не считается выполненной.

Не проверены Safari/iOS, физические устройства, полевые p75 LCP/INP/CLS и нагрузка настоящего viewer. Не выполнены mobile, реальные viewer/CRM/доставка формы, CMS и ИИ. Официальное назначение шрифта не подтверждено; известные корпоративные источники и точный вопрос перечислены в VISUAL_DELIVERY.md. Приёмка владельцем остаётся отдельным решением.

Убрано дополнительное уменьшение кадра лота. В браузере проверены project/space/lot и reduced-motion: clip-path none, border-radius 0px; снимки обновлены.

Для устранения возможности старого браузерного кеша каждый URL Media теперь содержит SHA-256-префикс файла в query-параметре v, включая hero srcset. Наличие старого кадра именно в браузере владельца не подтверждено; это устранение возможной причины, а не установленный диагноз. Проверка опубликованного сайта дополнена загрузкой и сверкой байтов всех пяти архитектурных WebP с reviewed файлами. Сценарий отказа изображения учитывает version query, а не теряет смысл после смены адресов.
