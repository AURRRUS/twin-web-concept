# Twin — проверка desktop 0.1

Дата: 19.10.2026. Репозиторий: исходный HEAD abb4c24152fc98da2426fea893211b752b854f6b плюс текущие рабочие изменения; новый commit не создан. Материалы: handoff v1.2 + overlay v1.3. Среда: Linux, Node 24.19.0, npm 11.9.0, системный Chromium через Playwright.

## Подтверждённые результаты

- PASS: все 76 файлов актуального комплекта существуют и совпадают по SHA-256. Официальный VERIFY_PATCH.py также вернул PASS; его runtimeTests=NOT_RUN относится к проверке архива, а не приложения.
- PASS: TypeScript `npm run typecheck`.
- PASS: статическая сборка `npm run build`, маршруты `/` и `/demo`.
- PASS: 8 тестов Playwright, без skipped/expected-failure. Машинный отчёт: `../artifacts/test-results.json`.
- Проверены H1 и реальные загрузки изображений, отсутствие pageerror на основном проходе, якорь канала и отсутствие горизонтального overflow на 1280/1440/1920.
- Все семь диалогов: открытие, URL, Escape, фокус инициатора. Дополнительно Back/Forward, прямой URL, циклический Tab/Shift+Tab, тема обращения.
- Четыре канала: click, ArrowRight, Home/End; отказ изображения не скрывает соответствующий текст и навигацию.
- Выбор переносится на `/demo`; корпус сбрасывает этаж и лот; этаж позволяет выбрать только доступный пример; неверный ID даёт сообщение вместо вымышленной записи.
- Форма: имя/компания/контакт/согласие, некорректная ссылка, сохранение полей, отсутствие POST. Успешная проверка полей показывает только отсутствие отправки.
- Reduced-motion сохраняет контент. Без JS доступны серверный H1, текстовые описания состава, якоря и честная страница демо.

## Фактические скриншоты

`first-screen.png`, `desktop-1440.png`, `desktop-1920.png`, `composition-desktop.png`, `delivery-desktop.png`, `component-dialog.png`, `demo-desktop.png` в artifacts. Первый экран, общая страница, карта, блок реализации и диалог визуально осмотрены. Это собственный рендер приложения, а не копии концептов.

Сохранены светлая основа, архитектурная панорама, фасад через несколько состояний, фронтальный демоинтерфейс, центральное ядро с шестью входами, широкая сцена канала и треугольник реализации. Типографика и точные кропы являются рабочей реализацией; pixel-perfect совпадение не заявляется. Нет шести самостоятельных изометрических мини-композиций: применён допустимый временный набор медиа и UI-иллюстраций. Нет motion камеры/морфинга: естественная прокрутка, короткие переходы, проявление связей и линии треугольника. Изменение reduced-motion применяется CSS без перезагрузки.

## Не выполнено и не подтверждено

- BLOCKED, отдельные подключения: настоящие Twin handshake/select/events, CRM, серверная доставка и политика данных. В исходниках нет необходимых ресурсов. Состояния реального транспорта loading/timeout/pending не выданы за проверенные.
- DEFERRED: mobile TW-M01…03; reflow в CSS не равен мобильной приёмке. Safari/iOS, физические устройства, слабая сеть и полный motion/performance-аудит не выполнены.
- NOT_RUN: полевые p75 LCP/INP/CLS, нагрузка настоящего viewer, внешняя аналитика. Крупные PNG преобразованы в WebP и SVG со встроенными оптимизированными медиа, но это не доказательство достижения полевых бюджетов.
- Не выполнены CMS, админка, ИИ/автоматизация, настоящие брони/платежи. Не опубликован сайт, не подтверждено восстановление в новой задаче после публикации среды.

## Исправления по фактической проверке

Исправлены циклический фокус диалога и CSS, ошибочно уменьшавший изображение в блоке реализации; повторная браузерная проверка прошла. Исправлена локальная настройка кеша npm и отключена телеметрия Astro, пытавшаяся записывать в недоступную домашнюю папку. Preview в тестах запускается с --ignore-lock в foreground, поскольку Astro в агентном окружении иначе запускает фоновый процесс и завершает команду до готовности.
