# Что подтверждено в проверенной версии

Осмотрена опубликованная страница ?v=6f4deea и прочитаны исходники ветки codex/twin-visual-recovery. Это исходное состояние до применения нового пакета, не отчёт о выполнении правки.

- В browser computedStyle H1 и H2 — RF Dewi, не RF Dewi Expanded. При viewport1363×936 H1≈52.57px, weight400, line-height≈57.83px. Journey H2≈52.57/56.78px weight400. Семейство неверное, величина берётся из clamp, а не из точного утверждённого набора.
- HeaderHero.tsx содержит hero-wash и конечную точку в H1. top-screens.css содержит два определения hero-wash; позднее даёт белый градиент с opacity≈.96 слева. Исправление только раннего правила не удалит засветку.
- site.css подключает обычный RF Dewi400/600/700. Прежний пакет содержал Expanded, но опубликованный исходный код его не использует. Наличие файла в архиве не доказывает применение к странице.
- Навигация Journey имеет колонку180px, непригодную для Expanded Semibold20px в слове «Пространство». Нужна новая геометрия, а не косметический font-family.
- verify-online.mjs проверяет /RF Dewi/ и явно ожидает обычный RF Dewi; его зелёный результат не подтверждает Expanded. Кроме того, он требует ширину медиа>780px при1440px и сохраняет обязательный скриншот. Проверку нужно актуализировать, не отключить целиком.
- Предыдущее задание запрещало публикацию без новой команды. Владелец теперь прямо требует публикацию сразу; этот конфликт снят01/05 и должен быть отражён в AGENTS.md репозитория.

Нельзя объяснить мотивы исполнителя по одному скриншоту. Здесь зафиксированы конкретные ошибки подключения, CSS, требований и проверки. Новый пакет закрывает эти неоднозначности.
