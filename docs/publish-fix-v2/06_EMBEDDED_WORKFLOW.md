# Рабочий протокол Web Concept Studio для этой правки

Применимые правила встроены в пакет; наличие навыка у исполнителя не требуется. Не искать внешний SKILL.md вместо исполнения.

Сначала реальные шрифты и полное содержание → затем композиция под их метрики → затем каскад → адаптив → проверка и публикация. Это внутренние шаги одной задачи, не этапы согласования с владельцем.

Сохранить выбранный образ: морской архитектурный первый экран, постоянный крупный фасад слева, средняя навигация и меняющееся предметное доказательство справа. Не начинать заново три концепта. Содержание не сокращать ради картинки. Общий контейнер и опоры, а не произвольное центрирование отдельных элементов.

Точные размеры02 имеют приоритет над старым растром. Референс задаёт уровень цельности, иерархию и связь зон, но не задаёт новые тексты и не разрешает вернуть засветление, конечные точки или удалённое левое украшение.

Проверять реальный render и промежуточные состояния скролла в ходе работы. Очевидные дефекты исправлять самостоятельно до окончания задачи. Не заменять работу описанием плана. Скриншоты/ролики и их одобрение не требуются. По завершении опубликовать по05 и дать ссылку.
