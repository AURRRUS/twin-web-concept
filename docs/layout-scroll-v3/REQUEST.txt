3. JOURNEY — ТОЧНАЯ МЕХАНИКА

Host460svh, panel100svh, полезный путь360svh.

p=clamp((scrollY−hostTop)/(hostHeight−panelHeight),0,1).

Чтение:
0–.19; .27–.46; .54–.73; .81–1.

Переходы:
.19–.27; .46–.54; .73–.81.

Внутри каждого перехода локальный t=0…1:
— старый H2 выходит0–.12, новый входит.14–.36;
— старый вопрос выходит.05–.20, новый входит.30–.58;
— старое изображение исчезает.30–.48;
— новое изображение появляется.50–.68;
— новое изображение scale1.025→1, Y12→0px на.50–.90;
— применение выходит.12–.28, новое входит.74–1;
— активный пункт меняется на.55.

Без двоения текстов и наложения двух полупрозрачных интерфейсов.
Пауза скролла останавливает сцену. Обратный ход обратим.
Повторный вход сохраняет соответствующее позиции состояние.

Переходы по пунктам ведут к p:
.095,.365,.635,.905.

Готовность изображения не изменяет p.
Загрузка запрашивает repaint, а не перестройку геометрии.
Один scroll-driver на host, один владелец transform каждого слоя.

Текстовые группы находятся в потоке.

на низком desktop16px.

Числовые значения:Dewi700,28/34px.
«Помогайте выбирать»:Dewi700,24/30px.
Пояснения:Inter450,16/24px.

Фраза «Помогайте выбирать» может занимать две строки.
Общая оговорка об условиях остаётся под композицией.

Раскрытие однократное, по прокрутке, без sticky и таймера.
Для каждой текстовой группы используй её собственную видимость:
g=max(previous,clamp((.85*viewportHeight−groupTop)/
(.30*viewportHeight),0,1)).

Текст появляется на g0–.25.
Для третьей группы слово меняется маской
«Эффектно → Эффективно» на g.55–.85.
Ширина слота рассчитана по более длинному слову.
Два слова одновременно не читаются.

Графика использует собственный монотонный progress.
Resize только пересчитывает геометрию.
Нижние факты не раскрываются заранее из-за входа верхнего.
