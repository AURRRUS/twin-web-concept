# R2 — реализация

Три компонента исправлены поверх7d0a628, а не откатом к ebca125. Фактические исходники и Pages защищены до изменений, отправленные SHA сверены с GitHub; BASELINE.md.

Journey: единый .story-j4-frame содержит header, route, media и sales. Только у него меняется --story-frame-width. Удалены --story-title-min, canvas.measureText и отдельная ширина медиа. Измерение после fonts.ready использует максимум4прохода: bands=frame.scrollHeight-media.offsetHeight, доступная высота panel за вычетом padding и2px запаса; ширина всего frame=min(availableWidth,1360,fitWidth). Если frame<800 или не помещается — switch естественной высоты. Шрифты не сжимаются. На1440×900 фактическая ширина около1002px, на1920×1080 около1273px; это ниже ориентиров из-за реального трёхстрочного максимального H2/служебной полосы. Общие края остаются едиными; ориентир не использован для обрезки.

Каналы: общий заголовок, пояснение,2×2nav, активная мысль/описание и одинCTA слева; grid42/58 во всех desktop-режимах, max1360/gap40–48. Фото справа целиком, max720/760, естественный1672/941. Верхний общий полноширинный header и28/72 удалены, включая switch. Кромки4/8px внутри собственной области; никакого растягивания фото до viewport.

Delivery: outer38/62 и единый720/760canvas. SVG viewBox0 0 720 760 с xMidYMid meet, вершины360,124/110,557.013/610,557.013; равенство сторон проверено после render. Модель — тот же Media core, позиция23.61/32.11%, ширина52.78%,ratio4/3; asset состава не менялся. Факты — DOM в координатах LAYOUT, без пересечения с моделью. На низких окнах canvas≤560, font28/22/14, уменьшены только внутренние интервалы фактов, чтобы сохранить нижний запас12px. Diagram_description берётся из R2CONTENT; mobile сохраняет полное описание. Нет sticky.

Драйвер разделён на storyLayout.ts (layout/geometry), salesStoryFrame.mjs+JSON (pure reference, побайтно совпадает с пакетом), storyPaint.ts (записи) и useStoryTrack.ts (lifecycle/refs). Формула p=(scrollY-hostTop)/(hostHeight-panelHeight), DOM-высоты, host без transform. Layout не вызывается на scroll или img.load. ResizeObserver предшествующего main обновляет top/geometry; повторное измерение только при изменении viewport/root-width/режима. При resize активный p/scene сохраняется, контролируемая коррекция scroll только у находящегося в окне pin.

StoryImage имеет состояния loading/ready/error. На подходе заранее eager/decode; правильный p никогда не подменяется готовностью картинки. Локальный placeholder/ошибка принадлежат выбранной сцене, есть retry/оригинал. Decode/error инвалидируют paint без нового scroll и без layout; проверено с задержкой и отказом сети. Слои двигаются одним RAF на событие; нет autoplay/перехвата wheel/touch/бесконечного RAF.

Generic entry использует внешние data-entry,420ms/Y14, story-frame400/Y12, easing(.22,.61,.36,1),0/60/120ms и launch70ms,max210. Внутренние data-story/quality исключены. Скрытие включается только после успешного observer; focus/anchor/fast-scroll/pageshow/popstate/reduced-motion раскрывают нужную внешнюю группу. Короткий entry может завершиться во время остановки; внутренний scene-frame от этого не доигрывает. Остановка проверяется после завершения внешнего entry. У исходного сравнения сохранено прежнее повторное внешнее появление/entry-cycle; у новых Journey/Channels entry — once, сами4сцены обратимы и повторяемы.

Сохранены hero/состав/демо/контакт/selection/MediaViewer и все сравнения. В ProductDemo/Composition/Contact изменены только entry-атрибуты внешних групп. Canonical desktop-геометрия ограничена root/min-width1100; мобильный frame естественный, без pin/min-width800. Реальные шрифты и исходные растры совпадают с архивом, включая quality-model.webp=public/media/core.webp. Новых изображений/шрифтов/библиотек не добавлено. Реальные проверки и публикация — RESULT.md.
