## Что отменено для V2
Чёрная левая колонка; два текста «Покупателю / Команде продаж»; «Помогайте превратить интерес…» внутри карточки; счётчики 02/04; квартира как центр всей системы. Прежний H2 «…это место» не переносить. Общие обзорные референсы эти ошибки частично содержат — они не являются указанием повторить их.
