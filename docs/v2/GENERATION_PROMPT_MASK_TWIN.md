# Generation Prompt Mask — адаптация Twin
Это художественная основа выбранных референсов; не исполнять генерацию заново при каждой инженерной правке. Источник метода — авторская mask из Pin Web Concept System; содержание, бренд и коммерческая модель ПИН не переносятся.

Создай ультрасовременный, кинематографичный и концептуально смелый desktop-веб-сайт Twin by TALENT — цифровой инфраструктуры продаж девелоперского проекта. Спокойный, точный, дорогой технологичный продукт. Аудитория — девелопер и его коммерческая команда; внутри показана история покупателя.

## Художественная конструкция
Одно пространство проекта раскрывается через архитектурные сечения. Крупный фотографический образ сохраняет узнаваемость и превращается в управляемую модель. Выбранная часть связывается с исследованием лота; весь Twin становится ядром цифровой системы. Та же модель используется в разных каналах продаж. Бронзовая линия служит краем сечения, выделением или связью компонентов, а не независимым украшением.
Менять масштаб и плотность. Соединять панораму, вертикальную архитектурную деталь, рабочий интерфейс и открытые типографические поля. Смысловые главы не обязаны быть одинаковыми полосами. Пространственная смелость подчинена чтению и действиям.

## Визуальный язык
Белая/тёплая светлая основа, графитовый текст, дозированная бронза. В Journey только бело-бронзовая колонка; графитовые поверхности — лишь внутри исходного product UI. Естественный синий остаётся в море/небе фотографий. Кристаллы и финансовая метафора ПИН не используются.
Крупные заголовки RF Dewi Expanded, UI и пояснения RF Dewi. Без serif, сжатия, искусственного bold и отрицательного tracking. Бронза выделяет конкретную смысловую часть заголовка. Воздух и дисциплина сетки, читаемая кириллица. Точки в конце заголовков запрещены.

## Содержание и состояния
Точные тексты из content.json, latest owner decisions выше изображений. Четыре режима Journey: location, compare, floor, living; изображать одно активное состояние. Карточка раскрывается, следующие состояния сдвигаются; большое изображение соответствует выбору. Верхний H2 обращается к девелоперу, внутренний текст описывает действия покупателя.
Не добавлять цены, доходность, KPI, новые обещания и функции. Реальные исходники проекта сохраняют геометрию и цвет. Точные логотипы и интерфейсы в реализации вставлять оригиналами.

## Приёмка
Референс оценивается по связям медиа, текста и действия, не по слову «современный». Общие изображения — направление, journey-white-bronze.jpg — локальный приоритет. Растр не доказывает работающую прокрутку, точный шрифт, адаптив и доступность. Эти свойства проверяет frontend workflow в браузере.
