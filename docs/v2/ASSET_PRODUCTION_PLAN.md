# Twin V2 — карта производства графики и эффектов
Статус: инженерный план по осмотренным overview-upper/overview-lower и последним решениям владельца, 27.10.2026. Графика этим заданием НЕ произведена. Новые параметры и варианты — предложения; текущие тексты/бренд/локальный Journey выше overview. Этот документ не является командой переделать сайт автоматически.

## Что было упущено
Референс связан продолжающимся фасадом, глубиной плоскостей, выходящими за границы объектами и тенью. В реализации одно изображение на секцию не обеспечивает этих отношений. Простая ступенчатая обрезка не заменяет объёмную архитектурную грань.
Маска задаёт художественный результат; отдельного готового эффекта/кода в ней нет. Layered parallax явно присутствует в motion-concept общего навыка, но не доказан неподвижным референсом.

## Минимальный пакет для пространственного перехода
A01 background: море/небо/территория без повторного фасада на месте движения foreground.
A02 facade: самостоятельный foreground с прозрачностью, тем же camera/crop/anchor.
A03 shadow: только если отдельная сложная тень необходима; для обычного плоского объекта достаточно CSS.
A04 plane/edge: CSS/SVG, геометрия из выбранного референса.
На каждый: источник, экспортный размер, целевой CSS-размер, visibleBounds, alpha, anchor, z-order, max displacement, scale, shadowMode, mobileVariant. Сначала сцена и состав layers, затем адресная генерация/извлечение недостающего; не целый сайт заново.

## Предлагаемый motion, не утверждённые числа
Hero/Journey: один общий графический материал с умеренным раздельным смещением; body-текст стабилен. Не возвращать засветление hero. При выходе сцена отпускает страницу.
Journey: приоритет читаемому каскаду и крупному визуалу, дополнительный parallax UI не нужен.
Каналы: управляемая обратимая стопка; не добавлять движение камеры поверх смены карточек.
Модель/треугольник: сначала разделить графику и тексты и исключить overlap; опциональная глубина не должна мешать чтению.
Mobile/reduced-motion: содержательная статичная версия или меньшая амплитуда, сохранённые controls.
