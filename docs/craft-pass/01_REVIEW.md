Опубликованный build-version.json указывает sourceCommit a81a2a47086c90975053734b5e45633d7458588e. Параметр v=6f4deea в ссылке не фиксирует старую версию сайта — фактический build уже новый.

## Web Concept Studio: композиция

Сохранить сильную основу: панорама → постоянный фасад → проект/пространство/лот → интерактивное демо → схема единой системы → каналы → запуск → контакт. Схема composition уже имеет крупный центр и связанные периферийные элементы: не превращать её в ряд карточек. Улучшение — единая последовательность появления, точная типографика и устойчивые связи зон, а не новое discovery или случайные эффекты.

Hero заканчивается на90svh: при высоте936px его нижняя граница842px и остаётся около94px следующей сцены. Это видимый край следующей секции, не доказательство лишнего margin. По пометке владельца сделать desktop hero100svh. Не исправлять полоску отрицательным margin, скрытием Journey или белой накладкой.

В Journey само сочетание большого фасада и правого доказательства сохраняем. Центральная навигация должна стать отдельной аккуратной вертикальной шкалой: номер → название → описание, без столкновения с медиа. Не уменьшать фото ради её поломки. H2 и абзац удерживают общую рамку, не прыгающую между сценами.

## Code Motion: почему ощущается дешёво

Текущий journeyFrame использует переход длиной.20 общего progress; исчезновение текста занимает.15 этого перехода. При пути sticky≈1591px это лишь48px scroll. Появление нового текста — около64px. Это расчёт по коду и измеренной геометрии, не замер FPS. Один обычный шаг колеса может проскочить почти всю текстовую фазу. Кроме того, весь механизм сводится к исчезновению текста и вертикальному открыванию картинки.

Система02 увеличивает читаемые фазы, оставляет паузы и использует лёгкое демпфирование только локального прогресса. Страница движется нативно. Скорость рук управляет сценой, при остановке движение быстро успокаивается, обратный ход воспроизводит ту же последовательность. Входы остальных блоков получают общую кривую и дозированное смещение. Больше эффектов не равно больше качества; исходная композиция и читаемость важнее.
