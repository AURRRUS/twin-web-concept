# Twin CORRECTION V2 — последнее прямое поручение владельца

Эти параметры заменяют конфликтующие положения DESIGN_HANDOFF. Новый архив не требуется: используются уже предоставленные шрифты и изображения.

- Все крупные H1/H2: реальный `RFDewiExpanded-Bold.ttf`, weight 700, letter-spacing 0, H1 line-height 1.18, H2 1.22. Без scaleX/scaleY и synthetic bold. 1440px: 44/38px; 1920px: 56/46px; 390px: 29/27px.
- Основной текст: настоящий Inter Tight variable, weight 450, letter-spacing .01em, line-height 1.55. 1440px: 18px; 1920px: 20px; 390px: 17px. Проверять локальные правила компонентов.
- Четыре этапа запуска: Inter Tight 600 20px для заголовков, 450 16px для пояснений; прежние 13/11px отменены.
- Второй экран: фасад слева, навигация в центре, медиа справа. `layoutMode` отделён от `motionEnabled`. На desktop при нехватке высоты и на 1024–1279px остаются фасад и одно активное состояние, кнопки работают без pin. Ниже 1024px — три последовательные статические сцены. Отключение движения не меняет desktop-композицию на три статьи.
- Активный desktop-треугольник: host 420svh, sticky-panel 100svh, полезная прокрутка 320svh. Фазы: 0–.08 вводная; .08–.18 заголовок; .18–.30 две стороны и факты; .30–.42 третья сторона; .42–.52 модель и демонстрация; .52–.72 собранный экран/пауза/«Эффектно»; .72–.84 вставка «ив»; .84–1 финальная пауза. Только обратимая нативная прокрутка.
- Короткие появления: заголовок → описание → визуал. Каждая карточка запускается собственным входом во viewport. Появление верхнего края composition-map не запускает все карточки. Парная линия появляется вместе со своей карточкой.
- Контакт: графит, светлый текст, бронза и исходные контуры Twin; форма непосредственно на фоне, без белой внешней карточки. Сохранить поля, валидацию и честный локальный статус.
- Исправить действующие канонические CSS-правила, самостоятельно проверить и сразу опубликовать на существующий GitHub Pages. Сверить computed styles именно опубликованной страницы, вернуть sourceCommit и фактические значения.

Не меняются стек, маршруты, исходные изображения, полный контент, выбор лота и демо; не выдумываются URL готового двойника или backend формы. Геометрия декоративных контуров взята из существующего public/favicon.svg, без новой генерации изображений.
