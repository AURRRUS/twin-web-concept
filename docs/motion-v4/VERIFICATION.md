# Motion V4 — реализация и проверка

Продолжение `51c028d` (код опубликованного `84fda42`), ветка `codex/twin-motion-v4`. Manifest нового архива проверен; четыре шрифта совпали побайтно с существующими файлами. Изображения и исходные PNG не менялись.

Hero: точный абзац, две строки desktop, Inter Tight40018/28 до1599 и20/30 от1600. Перенос второй строки разрешён только при измеренном вмещении; mobile естественный текст. Резерв прежней высоты абзаца сохраняет положение CTA. Journey: медиа624/680/720/840px на1280/1366/1440/1920 соответственно; навигация той же высоты, бронзовый active, без connector-линий к фасаду.

Delivery использует один локальный scroll rAF с CSS-переменными, без App setState/таймеров; host230svh, panel100svh, steps после host. Все SVG пути/координаты и размер модели сохранены. Дилемма предшествует ответу; стороны/модель/ответ/слова следуют storyboard. Вставка «ив» измеряется невидимым DOM probe вне скрытого визуального слова: первый вариант с probe внутри скрытого слова давал нулевую ширину и был исправлен до публикации. Во время вставки X основы «Эффект» неизменен; «но» сдвигается на фактическую ширину глифов. Screen reader получает один статический полный текст в каждом смысловом месте; aria-live не используется. Низкий desktop — flow с однократным входом модели, mobile/reduced-motion/no-JS — полная статическая сцена.

Один initCraftReveals: title-mask, workspace900ms, центрY16, пары120/220/320ms с синхронными связями; channels header/табы сразу читаются, фотография раскрывается маской900ms, её shell не пересоздаётся при tab switch; contact720/840ms. Delivery исключён из общего observer. Focus/deep-link показывают содержимое немедленно.

Typecheck, build и24 Playwright-теста пройдены. Целевые viewport1440×900,1366×768,1280×800,1920×1080,390×844; дополнительно320 и768px, низкий viewport, no-JS/reduced-motion. Проверены полные тексты, реальные custom-глифы, отсутствие overflow, фиксированная рамка сцен, клавиатура, исходные диалоги/выбор/каналы/демо/форма. Рабочие промежуточные кадры просмотрены, включая частичную вставку букв.

Отдельный медленный проход нативным wheel записывает start/middle/final каждой роли в artifacts/motion-v4-browser-check.json. Для скролла40 frame samples, median16.7ms/p95≈16.8ms, зарегистрированных long tasks нет. Это один headless cloud прогон, не обещание производительности устройств. При реальном переключении headless-вкладок document остаётся visible; отдельно проверен visibilitychange-resume (после возврата правильное «Эффектно»). Реальные Safari/iOS и физический trackpad не проверены. Точный публичный SHA после публикации фиксируется в artifacts/online-verification.json.
