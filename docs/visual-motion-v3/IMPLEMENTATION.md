## Движение и найденные дефекты

- journeyMotion.ts теперь реэкспортирует готовый journeyFrameV3.mjs с .d.mts. Старая timeline удалена. Driver220ms без скачка при большой дельте. Title/body opacity комплементарны, clip-path текста none; изображение не заменяет src, старые слои остаются под новыми в постоянном z-order.
- После просмотра реальных наложений Black60 применено прямо разрешённое03_MOTION сокращение heading-crossfade доq.08–.24. DOM title state переключается на середине этого интервала. Остальные формулы пакета сохранены. Математический check10001 кадров перепроверен на интегрированном модуле.
- Удалена преждевременная отмена входа на atPin. Первое состояние раскрывается title→body→media. Реальный вход в pin не отменяет WAAPI; прямой hash/кнопочный переход может собрать кадр для доступности.
- Обнаружен выход входного scale1.06 медиа за правый край. Анимация перенесена на вложенный scene-sheet-entry внутри неподвижной clipping-рамки scene-materials. Край/размер рамки при входе и переключениях не меняется, горизонтальная прокрутка не появляется.
- Исправлены прямые hash project/space/lot: начальное восстановление после готовности шрифта/размеров, без изменения маршрутов; только явный hash вызывает snap. Сохраняются cleanup, resize, keyboard и visibility lifecycle.
- Craft меняет действующие параметры:100/700 title,360/650 body,600/1050 media; scale1.06,Y−32; карточки0/700 от собственного входа. Небольшие heading-группы —80%, самостоятельные media/cards85%. Скрытые fallback не наблюдаются; при смене breakpoint регистрируется появившаяся версия. Парная SVG-линия привязана к карточке. Mobile350ms/scale1.02, reduced-motion без движения.
- Delivery остаётся420svh/100svh/320svh. Фазы не растянуты и не заменены общим fade; слова измеряются в Semibold600, карточка демо и число доступны без ожидания p1.
