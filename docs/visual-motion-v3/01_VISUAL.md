Добавить отдельный @font-face900 с `src:url('../assets/fonts/RFDewiExpanded-Black.ttf') format('truetype')` при размещении файла в src/assets/fonts/. Использовать один family и реальные статические400/600/700/900; у статических TTF не назначать диапазон. font-style:normal,font-synthesis:none,font-stretch:normal. Не пытаться получить900 из 700 синтетическим утолщением. Обновить preload так, чтобы нужный900 действительно загрузился до измерения слотов.

Не заменять семейство в UI на системный sans. Black применяется к большим смысловым заголовкам, а не ко всем мелким словам и полям.

Формы и служебный текст минимум 14 px, labels16 px, inputs18 px. Заголовки без конечных точек. Предлоги связывать короткими неразрывными группами, без длинного nowrap и overflow.

Проверить каскад не только общих h1/h2/p: `.scene-title-group h2`, `.delivery-copy .delivery-answer`, `.contact-copy h2`, `.map-component h3`, `.launch-steps h3/p`, `.hero-copy p` и скрытые состояния могут переопределять значения. Внесение нового @font-face без назначения900 узлам не считается работой.

## 3. Композиция Journey с увеличенным заголовком

Сохраняется выбранная архитектура: фасад29% viewport слева на всю высоту; справа71%; верхний заголовок/описание на всю правую область; ниже навигация 190 px на1440/220 px на1920 и медиа до правого края. Правый inset40/56 px, gap24/32 px. H2 две строки из JSON, без нового переписывания копирайта.

Верх правой области 32 px; eyebrow→H2 12 px; H2→body20 px; body→нижняя композиция 28 px. Для 900 px высоты начать с медиа16:9; общий реальный footprint измерить после загрузки900. Нельзя сохранять старые большие отступы и потом уменьшить заголовок, потому что «не влезло».

Если для честного16:9 медиа/текста места недостаточно: сохранять три зоны в auto-height, фасад растягивается по высоте всей композиции. Pin выключается, расположение и выбранный активный материал сохраняются. Не сжимать фото, не резать важный UI, не прятать текст. Не превращать laptop в три большие статьи из-за одного fits=false. layoutMode и motionEnabled уже разделены — сохранить исправление.

На1024–1279 px фасад24%, компактная навигация 180 px, один выбранный материал; на<=599 px декоративный фасад разрешено убрать. Навигация кнопками доступна с клавиатуры. Без JS все три главы доступны обычным потоком.

Hero: сохранить чистую фотографию, две смысловые строки H1, подводку и четыре канала, CTA. Позиция группы ориентир 20 svh, но она не перекрывает архитектуру и CTA не уходит за край. На desktop первую строку проверить реальным900: при нехватке ширины использовать44–48 px на1280–1440, не отрицательный трекинг.

Бронзовые фразы: «инфраструктура продаж», «проект ценным», «пространство», «конкретный лот», «цифровая основа», «одна основа», «все три качества», «на вашем проекте». Проверить контраст на реальном фоне, не ставить белое засветление поверх hero.

Маршрут запуска и графитовый Contact из V2 уже реализованы: сохранить. Довести их шрифты по новой таблице без повторного редизайна. Footer остаётся в графитовой среде, форма без внешней белой карточки; поля/consent/честный локальный статус не удалять.

Внутренние карточки основы и изображения каналов не перепридумывать. Существующий демопереход сохранять; настоящий Twin URL/API, новые изображения и backend формы остаются отдельными зависимостями.
