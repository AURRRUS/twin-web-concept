# Живая анимация: каскад без двоения
Естественный scroll, DOM-текст и управление с клавиатуры. Один runtime проекта. Второй smooth-scroll и canvas для обычной смены изображений не нужны. Разделить вычисление состояния и применение к DOM.

## Journey
Один progress P от0 до1, вычисляемый из позиции host и фактического пути sticky panel. Высота300svh из нынешнего кода — baseline, а не самоцель. После сборки подобрать длину: все3 состояния имеют читаемые остановки, одинаковый кадр не приходится бессмысленно пролистывать.
Стартовые зоны:0–.18 состояние1; .18–.38 переход1→2; .38–.62 состояние2; .62–.82 переход2→3; .82–1 состояние3. Это начальная техническая настройка для просмотра, не заранее проверенная режиссура.

Каждый переход использует локальное q от0 до1:
1. q0–.15: старая текстовая группа уходит, opacity1→0, Y0→−8px. Старое изображение полностью непрозрачно.
2. q.15–.35: новая текстовая группа появляется, opacity0→1, Y12→0px. H2, надзаголовок и абзац относятся к одной сцене. Небольшой stagger абзаца допустим; к q=.35 вся группа готова. Активная навигация меняется на новую сцену при q=.35.
3. q.35–.90: новое изображение раскрывается вертикальной clip-path/overflow-маской поверх старого. Оба изображения opacity=1. В каждой точке рамки виден один исходник. Старое снизу, новое сверху; при q=.35 crop100%, при q=.90 crop0%. Без scale, warp и сдвига встроенных букв.
4. q.90–1: чистое новое состояние, без догоняющего движения.

Заголовок должен опережать картинку — это прямое решение владельца. Краткое опережение текстом старого визуала намеренно; новый H2 со старым абзацем и старой навигацией на протяжении всей смены изображения недопустим.
Не применять прозрачный crossfade двух UI-скриншотов: текущая версия при P≈.30 останавливается в двоении. Не скрывать это blur. На любой позиции рамка заполнена, двойных букв нет. Обратное движение — та же функция P. Быстрый скролл сразу даёт нужный frame, без очереди setTimeout.

Click/Enter/Space по навигации перемещает обычный scroll к устойчивому состоянию. При reduced-motion — native static sequence из3 сцен. Управлять aria-hidden/inert по смысловому состоянию, без покадрового aria-live. Скрытая вкладка не крутит лишний rAF. При resize пересчитать геометрию, не возвращать человека к началу страницы.

## Hero и остальные взаимодействия
Первый кадр полноценный, H1/CTA доступны сразу. Лёгкий однократный reveal текста и CTA допустим после загрузки шрифта; не задерживать LCP декоративным preloader. Без автономного zoom/parallax.
Кнопки: спокойная реакция поверхности, короткое движение стрелки до4px, press1px, видимый focus. Общий язык состояний основных CTA, без прыгающих карточек.
Выход Journey обычным scroll, без резкого переноса следующего блока. Локальные reveal ниже не оставляют контент прозрачным после завершения. Не обещать60fps без измерения.
