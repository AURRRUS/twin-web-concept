# Twin — visual recovery, 21.10.2026

База: `cef8f33be718aa2667836ffa7323da86e1e350f3`, исходная ветка `codex/twin-top-screens-v2`. Перед работой обе удалённые ветки проверены; новых изменений поверх этой базы не было. Работа: `codex/twin-visual-recovery`. Production не обновлялся.

## Видимый результат

- В первых двух экранах восстановлен естественный межбуквенный интервал предоставленных RF Dewi / Inter Tight; прямоугольный вырез фасада заменён цельной диагональной границей.
- Hero получил более уверенный масштаб с сохранением двух смысловых строк и чистого морского фона. Опоры логотипа, H1 и CTA сохранены.
- Постоянный фасад увеличен с360px до576px при1440px. Верхняя текстовая зона занимает пространство над навигацией и медиа; нижняя сцена связана общей сеткой и иллюстративным connector, без привязки к вымышленному этажу.
- Полный текст трёх состояний вынесен в `src/lib/journeyContent.json`, без сокращений.
- Надзаголовок, H2 и абзац меняются одной группой. Навигация переключается после её появления. Затем непрозрачная вертикальная маска открывает следующее изображение. Opacity всех UI-изображений постоянно равна1; прозрачного смешивания букв нет.
- Проверенный кроп затрагивал внешний UI, поэтому оставлен полный кадр16:9. Через «Развернуть изображение» открывается полный исходный PNG, с Escape и возвратом фокуса. БезJS ссылка открывает оригинал напрямую.
- Sticky определяется измеренной высотой текста, навигации и картинки. На1366×768 и1280×800 сцена помещается; при недостатке высоты — обычный поток, без пустого270vh-хвоста. На390/768px и reduced-motion — все три статические сцены.
- Уточнён контраст hero, бронзовых CTA и вкладок каналов. Палитра остаётся существующей; новые цвета бренда и шрифты не вводились. Локальный reveal нижних секций сокращён с640 до420мс.
- Нижние секции, центральная модель, треугольник, viewer/demo и локальная форма сохранены.

## Сравнение с направлением

Референс открыт как изображение и сопоставлен на1440px с результатом: крупная архитектура вместо боковой полосы, общий верхний текстовый уровень и белое поле, компактная навигация у фасада. Растровая четырёхстрочная версия H1 и удалённое меню hero не копировались. Референс не использован для удаления composition/delivery или создания новых функций. В отличие от иллюстративного референса, демонстрационный UI сохранён целиком.

## Запуск

Текущий dev-preview: `http://localhost:4324/` в рабочей среде. Этот loopback не является публичным адресом владельца.

Из исходников: `npm ci`, затем `npm run dev -- --ignore-lock --port 4324`. Проверки: `npm run typecheck`, `npm run build`, `npm test`.

Отдельный готовый архив `TWIN_VISUAL_RECOVERY_PREVIEW.zip`: распаковать, выполнить `python3 serve.py`, открыть `http://localhost:4321/`. npm и сборка для архива не нужны. Приёмочный preview не опубликован на production.

Доступных навыков design-review/code-motion в каталогах cloud/executor и файлах среды не найдено. Использовано самодостаточное ТЗ пакета. Для диагностики среды прочитан cloud-environment-runtime; публичное перенаправление порта в текущей среде не предоставлено.
