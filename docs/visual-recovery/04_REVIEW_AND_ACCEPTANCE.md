## Обязательная приёмка исполнителя
1. Сопоставить эталон и результат на одинаковой ширине. Показать крупную архитектуру, иерархию и связь зон. Наличие3 колонок само по себе не является успехом. Старый референс не отменяет новый фон hero и его2 смысловые строки.
2. Проверить1440×900,1366×768,1280×800,1920×1080,390×844,768×1024. Полный текст без обрезки и наложений. Mobile не является уменьшенной копией desktop.
3. Прямой медленный проход1→2→3; быстрый1→3; обратный3→2→1; остановки q=.1,.25,.5,.75,.95. Нет двоения, пустых рамок, скачка размеров и старого абзаца после завершения текстовой фазы.
4. Tab/Enter/Space, focus, Escape в диалоге полного изображения и возврат фокуса, reduced-motion, resize и отключённый JS. Контраст обычного текста≥4.5:1, крупного≥3:1 — по реальному фону.
5. Проверить /demo, сохранение контекста project/building/floor/lot/view, контакт, возврат, base path и все текущие секции. Не отправлять форму внешним получателям.
6. Build/lint/typecheck и существующие релевантные тесты по package.json. Console/Network без новых ошибок. Плавность проверить записью/профилем на указанном viewport; один screenshot не подтверждает FPS.

Сдать runnable preview, изменённые пути/commit, desktop/mobile screenshots, короткую запись scroll, таблицу PASS/FAIL/NOT_TESTED. До сдачи самостоятельно исправить очевидные дефекты. Непроверенное обозначить прямо.
