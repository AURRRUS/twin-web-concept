# Journey V4–V6 R1

Добавлены самостоятельные JourneyV4 / JourneyV5 / JourneyV6 после исходного и1–3. Старые компоненты сцен, каналы, треугольник, Hero, демо и форма сохранены. Регистрация через comparisonCases: любой вариант удаляется отдельной записью, импортом компонента и его CSS. Общие helpers не содержат глобального активного состояния. Все DOM-запросы движения ограничены собственным root; RAF, listeners и observers очищаются.

CONTENT и MOTION скопированы без смысловых замен. Четыре PNG из архива совпадают побайтно с существующими final-r2/journey; используются прежние URL без дублирования. Все12увеличений открывают исходники в native dialog с Escape и возвратом фокуса.

Движение — чистая функция положения scroll: host500svh, panel100svh, полезный путь400svh. Чтение0–.16/.28–.44/.56–.72/.84–1; переходы.16–.28/.44–.56/.72–.84. Локальные окна H2/описания/медиа из MOTION. Нет очередей таймеров, autoplay, перехвата wheel/touch или глобального snap. Обратный ход и повторный вход вычисляют тот же кадр. Клики ведут в.08/.36/.64/.92; клавиши стрелок/Home/End работают в навигации.

V4 — одна большая сцена с верхней независимой текстовой полосой и вертикальной маской смены изображения. V5 — настоящий горизонтальный track с четырьмя собственными сценами; движение только между чтением, виден соседний фрагмент. Последняя остановка учитывает полный scrollWidth. V6 — закреплённый текст, нижняя маска входящей плоскости, уменьшение старой; две нейтральные кромки. Движущиеся плоскости ограничены окном визуала и не перекрывают подпись.

При width<1024, height<600 или reduced-motion — компактный переключатель без длинного трека. Без JS все4сцены видны последовательно. Неактивные слайды и перекрытые элементы исключены из фокуса через inert. Ссылки сравнения0–6 сохранены; на mobile индекс прокручивается внутри себя. Прямые якоря новых pin-секций выравниваются по панели, включая переход между якорями в уже открытой странице.

Канонические файлы шрифтов репозитория не заменены. Аудит fontTools подтверждает Expanded Black900 / Semibold600 / Bold700; fvar Inter Tight100–900 поддерживает450. Браузерные проверки проверяют фактически отрисованные custom font glyphs через CDP и computed styles; font-synthesis:none, без scaleX. Размеры H2 V4 44/54, V5 44/52, V6 40/50 при1440/1920; низкие окна36/36/34. Leading1.12, tracking0; навигация600/1.25; основной текст450/1.55/.015em.

## Измеримое ограничение пропорций

У настоящего Black текст не помещается в номинальные34% V6 с предписанным кеглем и максимумом3строки. Для сохранения шрифта/кегля и смыслового бронзового фрагмента введена минимальная ширина текстовой колонки по реальным метрикам самого длинного бронзового фрагмента. На1440 это около519px (39.6% доступной ширины), на1920 около648px (37.5%); на1366 около41.4%. Остаток получает изображение. Это отклонение от буквального34/66; сжатие букв и уменьшение кегля не применялись.

Аналогичный intrinsic minimum в V4 сохраняет максимум2строки: на1440 около783px вместо номинальных761px. На1920 заданная переменная gutter64px сочетается с max-width1760px: фактическое внешнее поле80px. Все изображения contain, целиком, с исходной геометрией; свободное пространство вокруг них намеренно сохраняется.

## Исправления по проверкам

У V5 снят общий grid-area для собственных H2/абзаца, чтобы текстовые строки не накладывались. У V6 ограничен выход плоскостей на подпись. Для старого варианта3 установлена eager-загрузка тех же изображений после готовности сравнений: при быстром проходе длинной страницы Chromium мог пропустить lazy-загрузку скрытых глав. Его сцены, текст, motion и композиция не изменены. Артефакт preservation.json подтверждает неизменность исходных движков/секций и старых функций вариантов1–3.

Команды: npm run typecheck; npm run build; npm test. Новые проверки — tests/journey-v4-v6.spec.ts, чистая математика20001кадра. Online-проверка: NODE_USE_ENV_PROXY=1 TWIN_EXPECTED_COMMIT=<SHA> node scripts/verify-journey-v4-v6.mjs. Снимки: TWIN_CAPTURE_URL=<URL> TWIN_CAPTURE_DIR=<DIR> node scripts/capture-journey-v4-v6.mjs.

Фактический финальный статус и опубликованный sourceCommit фиксируются отдельно в ONLINE.md после проверки GitHub Pages. Desktop Chromium проверен автоматизированно и визуально; физические iOS/Safari не проверялись.
