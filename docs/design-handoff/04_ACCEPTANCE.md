# Проверка перед немедленной публикацией

Проверки выполняет исполнитель самостоятельно. Скриншоты допустимы как внутренний инструмент, но не как отдельный этап согласования и не как замена публикации.

## Статика

- Каждый объявленный font-face реально загружается без 404; Semibold использует файл 600. Проверить computed styles и шрифты в DevTools, не только CSS-имя. Нет синтетического bold. Текст на AI-макете не доказательство загруженного шрифта.
- Проверить ширины 1920, 1440, 1280, 1024, 768, 390, 360px и desktop height 800/900px. На низком viewport включается обычный поток вместо непомещающегося pin.
- Не пропали абзацы, каналы, CTA, карточки и якоря. В заголовках нет конечных точек, нет висячих предлогов, наложений и горизонтального overflow.
- Hero: две смысловые строки H1 на desktop, четыре канала, CTA внутри видимой композиции, фото без засветления.
- Journey: большой левый визуал, читаемая навигация, широкий правый материал. Без стрелок в фасаде, бежевых капсул и обрезанного важного UI. Все состояния имеют одинаковые устойчивые слоты.
- Треугольник: «все три качества», первичное «Эффектно», отсутствие капсул, одна реальная ссылка на demo без ложного Play. Числа с существующего сайта сохранены без усиления обещания.
- Бронзовые акценты выбраны по словарю; цвет текста измерен на фактическом фоне. Обычный текст 4.5:1, крупный 3:1 минимум. Фокус и кликабельные области доступны.

## Движение

- Заголовок, описание и изображение имеют разные интервалы; при медленном scroll видны отдельные фазы. Один щелчок колеса не запускает автономный полный переход.
- Проверить p второго экрана .10/.20/.26/.325/.40/.45/.525/.60/.725/.85/.925 и обратный ход. Нет пустого медиаслота, flash, рывков высоты, исчезнувшего текста.
- Новое изображение сначала увеличено, затем опускается и уменьшается до исходной геометрии. Предыдущее лежит под ним. Это видно по внешним границам слоя, не только по кропу изображения.
- У каждой главы есть hold на чтение; увеличение не перекрывает текст. Никакой общей opacity на родителе, которая маскирует собственную хореографию детей.
- Вставка «ив» не сдвигает соседние слова. Слово обратимо по scroll. Треугольник соответствует стадиям смысла.
- Все обычные разделы имеют короткий каскад, а не статичны; при обратном просмотре не прячутся повторно. У основы/каналов нет лишних длинных pin.
- Проверить быстрый scroll до футера, навигацию якорями, клавиатуру, загрузку картинок с задержкой/ошибкой, resize, reduced-motion и no-JS. Контакт и demo остаются доступны.
- Сборка и проверки текущего проекта проходят. Старые тесты с другим font-family/геометрией обновлены по реальному заданию, а не удалены ради зелёного статуса.

## Публикация и отчёт

Опубликовать штатным механизмом существующего GitHub Pages. Не создавать новый сервис, домен или ветку публикации без причины. Убедиться, что online build соответствует новому source commit и assets не 404 на base path /twin-web-concept/.

В финале дать ссылку и commit, кратко описать выполненное. Отдельно явно отметить непредоставленный готовый двойник и не заменённые изображения каналов. Не объявлять эти зависимости закрытыми и не скрывать провал публикации за фразой «всё готово».
