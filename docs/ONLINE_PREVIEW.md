# Онлайн-просмотр: состояние

Владелец явно запросил ссылку на работающий сайт. Это новое поручение разрешает онлайн-размещение демонстрационной версии, заменяя прежнее ограничение публикации для этой цели.

Исходный код сохранён в GitHub в ветке `codex/twin-desktop-v1-3`. Подготовлена сборка для GitHub Pages с базовым путём `/twin-web-concept`. Отдельно проверены гидратация React, диалог, канал, выбор и переход к демо, загрузка изображений на этом базовом пути.

Статическая сборка предназначена для ветки `twin-preview`, корневой папки. Содержит только публичную сборку приложения, без исходных ТЗ и настроек среды; .nojekyll включён.

Блокер включения Pages: соединение с `api.github.com` отклоняется сетевым прокси среды, HTTP CONNECT 403, до проверки авторизации GitHub. Native Git read/push работает. Токен GitHub присутствует; новый токен не запрашивался. Дополнительное разрешение сетевого доступа для turn не сняло ограничение прокси. В черновик сетевых настроек добавлены `api.github.com` и `aurrrus.github.io`, без замены пресета package_managers. Сохранение черновика не применяет правила к машине.

Вариант включения без GitHub API этой среды: владелец открывает Settings → Pages своего репозитория, выбирает Deploy from a branch, ветку twin-preview, папку /(root), Save. Только после включения и завершения Pages deployment можно утверждать, что онлайн-адрес работает. Если GitHub сообщает ограничение тарифного плана для частного репозитория, не менять видимость и не покупать тариф без поручения.

Ожидаемый адрес после успешного включения: https://aurrrus.github.io/twin-web-concept/ . До фактической проверки не объявлять его работающим.

Для повторной сборки: `TWIN_BASE_PATH=/twin-web-concept npm run build`. Обычный dev использует `/`. Форма и viewer по-прежнему демонстрационные, реальные обращения не отправляются.
