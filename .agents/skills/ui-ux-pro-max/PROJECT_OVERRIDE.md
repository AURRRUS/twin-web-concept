# Приоритет проекта Twin
Прочитать `.twin/DESIGN.md`, `.twin/tokens.json`, `.twin/DECISIONS.md` и `.twin/ROUTING.md` из корня репозитория. Они выше дефолтных тем, примеров, шрифтов и внешних DESIGN.md навыка. Не устанавливать инструменты и не приписывать отсутствующие навыки. Относительные ресурсы самого навыка разрешать от его папки. Чтение навыка не равно вызову отдельного агента.
