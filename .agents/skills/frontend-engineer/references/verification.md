# Приёмка
Отдельно фиксировать наличие файлов, проверки кода, браузерные действия, визуальное суждение и опубликованную версию. Не превращать один уровень в доказательство другого и не суммировать их в выдуманный процент качества.
Для страницы пройти секции последовательно, а не только открывать якоря. Для компонента осмотреть каждое состояние с настоящим содержанием.
Выбрать широкий desktop, низкое окно laptop, узкий mobile и пограничную ширину layout. Расширять матрицу по дефектам; не прогонять всё для правки одной буквы.
Проверить шрифты, переносы, интервалы, группировку текста/CTA, иерархию, crop, clipping и overflow. В резервируемом слоте проверить самую короткую и длинную сцену.
Движение проверить по motion.md. Проверить keyboard/focus/hidden controls/reduced-motion, холодную загрузку и ошибку изображения при затронутой readiness. Не показывать ложный успех формы без backend.
У восстановленного UX/UI-корпуса есть runtime-зависимости. Проверять их до запуска команд, передавать путь реального проекта. Upstream reports и sample-токены не являются проверкой сайта. Полный upstream gate-suite не объявлять выполненным без фактического запуска.
Публиковать по авторизации проекта, сохраняя резерв. Внутренние снимки не требуют согласования владельца, если оно не запрошено.
