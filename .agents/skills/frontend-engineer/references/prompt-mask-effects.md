# От Generation Prompt Mask к реализации
Источник художественной конструкции: pinwebconceptsystem/references/generation-prompt-mask.md, авторская маска 17.09.2026. Связанный механизм: web-concept-studio/references/motion-concept.md. Переносить метод, не палитру, кристаллы, тексты или продуктовые правила ПИН в чужой бренд.

## Что источник действительно задаёт
Маска требует: общий материал/ось/свет связывают несколько смыслов; масштаб и отношения меняются ниже hero; не стопка независимых полос; один доминирующий центр; архитектурная глубина и взаимодействие материалов. Это художественные требования, не готовые CSS-алгоритмы.
Каталог motion-concept явно содержит layered parallax, mask/wipe, sticky whole→detail, scale/crop, горизонтальную серию и типографическое раскрытие. Статичный ImageGen не доказывает, какой из них использован: движение нужно спроектировать.

## Карта переноса
| Видимый приём | Реализация | Необходимый материал | Проверка |
|---|---|---|---|
| Фасад соединяет hero и следующую сцену | общий scene-wrapper, локальные слои/маска, согласованная система координат | фон, foreground facade alpha, восстановленный фон за ним | нет шва/двойного здания, совпадает опорная точка |
| Объект выступает за границу секции | bounded absolute-слой в общем предке, независимый DOM-поток текста | вырезанный объект, alpha, опциональная контактная тень | объект не обрезан overflow предка, текст не перекрыт |
| Приподнятая белая плоскость, углубление | CSS gradients + borders + contact/ambient shadow; сложный силуэт SVG | raster только для выраженной фактуры/реалистичной геометрии | видна глубина при отключённом motion |
| Физическая стеклянная оптика/каустика | подготовленный raster/light pass; shader только при необходимой динамике | чистый оптический слой без текста | простая полупрозрачная рамка не выдана за рефракцию |
| Тонкая направляющая между сценами | SVG path в общей композиционной системе | координаты пути, не картинка всей страницы | линия связывает конкретные опоры; не перечёркивает текст |
| Объёмная стопка карточек | DOM wrappers, transform, z-index, собственная тень каждого слоя | фотографии каналов, отдельный UI при необходимости | читается толщина/порядок, reverse и controls доступны |
| Панорама → деталь | тот же исходник, изменение crop/scale либо подтверждённый второй вид | достаточное разрешение, focal points | сохраняется объект; нет выдуманного движения камеры |
| Несколько глубин при scroll | отдельные transform wrappers с разными амплитудами | независимые слои, overscan, clean plate | нет дыр и рассинхрона теней, текст стабилен |
| Вертикальная рубрика и большие буквы | DOM, writing-mode/rotate только короткого маркера, clipping в декоративном wrapper | реальный шрифт | не основное чтение, mobile вариант задан |

Выбрать 1–2 характерных приёма для сцены, остальные оставить спокойными. Не добавлять все эффекты маски как обязательную норму.
Отделять свет в фотографии, CSS-свет поверхности и самостоятельный оптический asset. Нарисованная тень от фасада не должна двигаться независимо от фасада. В Twin сохранён запрет осветляющей вуали первого экрана: он не запрещает контактные тени панелей, но запрещает снова засветлить hero.
