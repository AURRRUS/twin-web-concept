# Маршрутизация
Находить актуальные навыки по имени через каталог среды. В файловой установке искать соседние SKILL.md по полю name; не переносить идентификаторы пакетов как обязательные пути в клиентский проект.
- web-concept-studio: универсальная композиция и развитие выбранного направления до handoff/реализации через профильные инструменты.
- pinwebconceptsystem: специализированный визуальный слой ПИН. Не применять к Twin или клиенту другого бренда. Не удалять и не сливать две веб-системы.
- ui-ux-pro-max: типографика, читаемость, управление и адаптив; целевой domain/stack-поиск вместо генерации новой темы поверх принятой.
- design-code: восстановленный инженерный ресурс, адаптер текущего стека, компоненты и семантика. Примерные токены не заменяют токены проекта.
- code-motion: исполнимые web-модули, storyboard и кодовый motion. Видео только по запросу.
- material-3: нужные состояния, формы, navigation/adaptive patterns; полная MD3-тема только при соответствующей задаче. Не назначать Roboto/плашки/палитру всему Twin.
- webapp-testing + доступный браузер: реальные состояния и действия.
- product-creative-producer: незакрытая продуктовая логика. real-producer только для соответствующей смысловой задачи.
Не требовать для каждой правки три концепта, 15 линз или команду субагентов. Делегировать только при разрешении задачи/среды. Последнее решение пользователя и канон конкретного проекта имеют приоритет.
