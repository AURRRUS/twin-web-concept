При 1440 px: фасад 0–360; навигация x392, ширина184; правая колонка x616–1376. Рамка 760 × 427.5, 16:9, object-fit:contain. Все три состояния резервируют общую высоту заголовков и абзацев через наложенные ячейки CSS Grid, поэтому рамка остаётся на одной высоте. H2 56px/1.08 Regular, абзац18px/1.5. Сохранены существующие файлы шрифтов проекта RF Dewi / Inter Tight, без заявления об иной оригинальной гарнитуре.

Прокрутка обычная; фазы вычисляются от её положения, без очередей таймеров. Абзац меняется после завершения перехода изображения. При высоте менее900px, ширине менее1280px и reduced-motion показаны три полные статические сцены.

Сборка и typecheck успешны. Автоматическая проверка включает точные абзацы, описания навигации, геометрию1440, обратимый каскад, доступность мобильного текста и переполнения на390/768/1280/1440/1920. Нижние секции не изменены. В hero добавлен только перенос перед «через агентов».
