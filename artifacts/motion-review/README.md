# Исправленные края, стыки фотографий и прокрутка

Актуальная итерация после замечаний владельца о белой полосе справа и рваной смене сцен. Предыдущие снимки в `grid-review/` сохранены для истории.

- Удалён принудительный резерв 15 px справа; панорамные секции занимают доступную ширину.
- Фасад и сменяемые кадры разделены явным отступом 16 px. Нижние края совпадают, кадры больше не изображают случайный непрерывный стык.
- Переключение кадров сглаживается через requestAnimationFrame; под переходом всегда остаётся непрозрачный кадр. Нет одновременного исчезновения двух изображений в белый фон.
- Появление заголовков и формы — opacity и небольшой translateY, без изменения размеров секций и перехвата колеса/тачпада. Reduced-motion и версия без JavaScript остаются читаемыми.
