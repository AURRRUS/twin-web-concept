# Twin by TALENT — рабочие инструкции
Начинать любую задачу с `TWIN_START.md` и `.twin/START.md`. Проверить `.twin/project.json`: действующая ветка исходников — `work/twin-site-system`; `main` может содержать только загрузчик. Не писать сайт поверх старого starter.
Последнее явное решение владельца выше старых документов. Зафиксировать новое решение в `.twin/DECISIONS.md`, не терять его в переписке.
Использовать реальные локальные навыки из `.agents/skills` по `.twin/ROUTING.md`. Не заявлять вызов специалиста, если прочитана только инструкция; помощников вызывать только когда это разрешено.
Все новые задачи оформлять по `.twin/TASK_TEMPLATE.md`, проверять `node scripts/twin-system.mjs task ID`. Шрифты, размеры, веса, интервалы, цвета брать из `.twin/tokens.json`, реальные файлы — из `.twin/assets.json`. Не заменять числовые параметры словами «жирнее» и «премиально».
Не переносить бренд ПИН в Talent. В заголовках не ставить точки в конце. Не оставлять короткие предлоги/союзы в конце строк; связывать их неразрывным пробелом со следующим словом без склейки длинных фраз.
Порядок: контекст → контракт → статичная композиция → адаптив → motion → браузерная проверка и исправления → публикация по разрешению задачи → запись результата. PASS сборки не означает визуальное одобрение.
Не просить владельца утверждать скриншоты перед разрешённой публикацией. Снимки — внутренний инструмент исполнителя. Не публиковать нерелевантные изменения и не откатывать более свежую работу.

## Отдельная V2 — явное исключение маршрута
Для задач «Twin V2», VIS-002 и ветки work/twin-v2 после общих правил обязательно читать V2_START.md. Рабочая ветка V2 — work/twin-v2; canonicalBranch V1 в main/.twin/project.json не является указанием переносить V2 в V1. Правила V2 выше прежних JRN-001 там, где явно отменены. Не исполнять pendingTask автоматически при запросе подготовки/ревью. Отдельный publish:v2 только в v2/; старый publish:preview не использовать для V2. Последний локальный reference и docs/v2/DECISIONS.md выше overview. Не менять файлы навыков без отдельной необходимости; они уже подключены.
