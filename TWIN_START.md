# Сайт Twin

Рабочая команда: **Сайт Twin: <правка>**.

Актуальные исходники и система находятся в ветке **work/twin-site-system**. Код приложения в main — старый starter; не использовать его для правок сайта.

1. Прочитать [.twin/project.json](.twin/project.json), получить canonicalBranch.
2. Открыть [полный вход](https://github.com/AURRRUS/twin-web-concept/blob/work/twin-site-system/TWIN_START.md), затем [регламент](https://github.com/AURRRUS/twin-web-concept/blob/work/twin-site-system/.twin/START.md) в этой ветке.
3. Использовать реальные навыки в .agents/skills и действующие решения, шрифты, токены и шаблон задания.

Команды:
- «Сайт Twin: подготовь ТЗ — …» — подготовка без изменения сайта, весь промпт текстом.
- «Сайт Twin: исправь … и опубликуй» — реализация, проверка, разрешённый выпуск и память в Git.
- «Сайт Twin: проверь …» — фактическое ревью.
