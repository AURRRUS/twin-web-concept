# Сайт Twin
Команда для работы: **«Сайт Twin: <что нужно изменить>»**.

- «Подготовь ТЗ» — исполнитель собирает задание и показывает весь промпт текстом; сайт не меняет.
- «Исправь / сделай / внедри …» — выполняет правку в рамках действующих решений. При «опубликуй» выполняет и выпуск после проверок; уже данное разрешение повторно не запрашивает.
- «Проверь / сделай ревью» — проверяет фактический результат, не выдаёт план за реализацию.

Вход исполнителя: [регламент](.twin/START.md). Память проекта: [решения](.twin/DECISIONS.md), [оформление](.twin/DESIGN.md), [задачи](.twin/tasks).
Каноническая ветка: `work/twin-site-system`, репозиторий `AURRRUS/twin-web-concept`. В `main` находится указатель на неё; не использовать старое приложение main как актуальную версию.
Последнее выполненное задание: `JRN-001` — новый второй экран опубликован. Фактическая версия и ограничения — в `.twin/tasks/JRN-001/ONLINE.md`. Следующую правку готовить от текущей канонической ветки.

Устройство памяти: Git хранит принятые решения и контракты; навык `twin-site` находит их; frontend-engineer отвечает за реализацию; браузерная проверка подтверждает результат. История чата помогает, но не заменяет эти файлы.
