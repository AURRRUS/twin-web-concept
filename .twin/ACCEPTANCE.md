# Приёмка
В RESULT.md каждый пункт имеет PASS / FAIL / NOT RUN / NOT APPLICABLE, метод и доказательство. Не заменять наблюдение обещанием.

| Гейт | Проверка |
|---|---|
| G0 Контекст | Актуальная ветка, чужая работа сохранена, scope и последние решения прочитаны |
| G1 Контракт | twin:check, twin:task ID, twin:test; ссылки и ассеты доступны, generated совпадает с tokens |
| G2 Реализация | Проектные typecheck/build и релевантные тесты; отсутствие новых JS/HTTP-ошибок |
| G3 Типографика | Реальный загруженный файл, кириллица, вес и роль; читаемые интервалы и переносы, нет синтеза и сжатия |
| G4 Motion | Вход медленно/быстро, остановка в середине, reverse, повторный вход, быстрые клики, resize, клавиатура, reduced-motion; нет двоения и зависания |
| G5 Адаптив | 1440×900, 1366×768, 1280×720, 1920×1080, 390×844, 360×800; нет обрезанного текста, перекрытий и горизонтального скролла; реальные устройства если доступны |
| G6 Визуал | Осмотр композиции в браузере: связность смысловых групп, ясный акцент, достаточная величина изображения, читаемость активной карточки; конкретные дефекты исправлены |
| G7 Выпуск | Публикация разрешена, резерв создан, фактический live sourceCommit совпал, затронутый сценарий проверен онлайн |

Изменение только документации не требует визуальной проверки приложения: указать NOT APPLICABLE. Недоступный браузер означает NOT RUN, а не PASS. Число тестов и computed styles не доказывают эстетическое качество. Внутренние снимки можно использовать для диагностики без этапа одобрения владельцем.
