# Форма задания
Исполнитель заполняет её из обычной правки владельца; владелец не обязан задавать CSS.

1. ID / режим / статус / исходный commit и опубликованный sourceCommit
2. Наблюдаемая проблема → ожидаемое изменение для пользователя
3. Scope: компоненты, разрешённые изменения, что сохранить
4. Точные тексты и источник решения; источники, реальные изображения и пути
5. Роли tokens.json для каждого уровня; новая роль отдельно с числами и статусом
6. Геометрия desktop / низкое окно / mobile, поведение при длинном тексте
7. Состояния, управление, keyboard, motion progress, reverse/re-entry, resize и reduced-motion
8. Проверяемые критерии приёмки, подходящие команды и браузерные сценарии
9. Publication allowed + основание; резерв, live-сверка и rollback
10. Нерешённые вопросы только если без них действительно меняется продукт

Машинная часть — task.json (см. JRN-001), полная постановка — TASK.md и при необходимости CONTENT/VISUAL/MOTION. PROMPT.txt генерируется для передачи текстом. Статус ready допустим только при заполненном контракте и проверке ссылок.
