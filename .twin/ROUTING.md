# Кто за что отвечает
| Задача | Обязательный навык | Результат |
|---|---|---|
| Любая реализация Twin | `.agents/skills/frontend-engineer/SKILL.md` | Код, адаптив, исправления, наблюдаемый результат |
| Иерархия, типографика, плотность | `.agents/skills/ui-ux-pro-max/SKILL.md` | Применимые правила к текущему бренду; целевой поиск по UX, не случайный стиль |
| Scroll, каскад, переходы | `.agents/skills/code-motion/SKILL.md` | Состояния, диапазоны прогресса, паузы, reverse и fallback |
| Визуальная приёмка | `.agents/skills/design-review/SKILL.md` | Дефекты с местом и исправлением, отдельное визуальное суждение |

`frontend-engineer` — ответственный исполнитель, другие навыки помогают по предмету. Для маленькой текстовой правки не загружать всю библиотеку. Навык — инструкция; он не равен отдельно вызванному агенту. Проверять наличие каждого пути. Прочитать PROJECT_OVERRIDE.md в подключённых навыках.
Для нового смысла дополнительно применять доступные product-creative-producer, real-producer, sales-producer; они не нужны для исправления отступа. Если их нет, не писать «вызвал продюсера».
Material 3 можно подключать для поведения контролов и доступности, если он доступен; его тема, Roboto, размеры по умолчанию не отменяют Talent. Web Concept Studio отвечает за концепт, не заменяет frontend-инженера. PIN Web Concept не является брендом Twin.
