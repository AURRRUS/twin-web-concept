Навык — инструкция, не запущенный агент. Проверять реальные пути и PROJECT_OVERRIDE. Для существенного конвейера запускаются исполнитель и отдельный reviewer с ID/evidence. Для маленькой правки подключать только нужного специалиста.
Для незакрытой смысловой задачи применять доступных product-creative-producer/real-producer/sales-producer. Не заявлять запуск отсутствующего навыка. Web Concept Studio отвечает за концепт; PIN Web Concept System и бренд ПИН не переносятся в Twin. Material 3 допустим для поведения/доступности контролов, его визуальные дефолты не отменяют Talent.

## Общий контракт и графика
Общий процесс: `.agents/skills/web-production/references/factory-contract.md`, `workflow.md`, `codex-handoff.md`. Производственный статус schemaVersion=2 и маршрутизатор принадлежат Web Production. Twin Site лишь отсылает к ним.
FE самостоятельно разбирает сцену и заказывает недостающие материалы. Исполнитель выбирается по `.agents/skills/web-production/references/image-routing.md`, с уточнениями Twin в `.agents/skills/twin-site/references/image-routing.md`. Приёмку пригодности слоя выполняет FE в контексте сцены, итоговый визуальный review — отдельный reviewer.
Вместо автоматического числа усилений у job есть конкретная причина, бюджет вызовов, защищённый объект, источник и лучшая версия. Перед серией нужен принятый образец. Правила конкретного доступного графического навыка читать перед его применением.
