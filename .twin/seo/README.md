# SEO Twin

Два целевых направления: «цифровой двойник для продаж недвижимости» и «интерактивная презентация недвижимости». Выбор по соответствию продукту и намерению поиска; частотность не измерена. «Виртуальный отдел продаж» — дополнительное описание, не отдельный главный запрос.

В Motion Preview обновлены title, description, Open Graph, Twitter и Organization JSON-LD. Утверждённый видимый H1 сохранён. Meta keywords не добавляется. Preview остаётся noindex,nofollow, чтобы тестовые версии не конкурировали с основной.

Перед индексированием нужен окончательный основной URL. На выбранной production-странице выставить self canonical и og:url, заменить preview image URL при переносе, разрешить index/follow, создать sitemap.xml только с production URL и robots.txt на корне основного домена. Не объявлять GitHub preview основной страницей автоматически. Старые тестовые версии оставить noindex.

Затем подтвердить домен в Google Search Console и Яндекс Вебмастере, отправить sitemap, проверить отрендеренную страницу и доступность текста/изображений роботам. Подключение кабинетов и результаты индексации пока не выполнены. Рост позиций не гарантируется метатегами: нужны измерение запросов, полезный контент и реальные внешние упоминания.
