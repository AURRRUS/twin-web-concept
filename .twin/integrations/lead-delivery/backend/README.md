# Twin — обработчик заявок

Получатели зафиксированы на сервере: bytalentru@gmail.com и iraks.romanov@yandex.ru.
Пароли и адрес обработчика не настроены: реальная отправка пока не включена.

## Установка

Node.js 22+, один постоянно работающий процесс, HTTPS reverse proxy и постоянный приватный диск.
`npm ci`, скопировать `.env.example` в `.env`, заполнить параметры SMTP отправителя, задать окончательный origin сайта и DATA_DIR вне каталога сайта. `npm test`, затем `npm start` под systemd или другим менеджером процессов.

Проксировать HTTPS `/api/leads` на `http://127.0.0.1:3000/api/leads`.
Если включён TRUST_PROXY=1, reverse proxy обязан перезаписывать X-Forwarded-For адресом клиента.
На GitHub Pages запустить Node.js нельзя: обработчик размещается отдельно.
В HTML добавить `<meta name="twin-lead-endpoint" content="https://HOST/api/leads">` только после настройки обработчика и проверки доставки на оба адреса. До этого сохранён прежний демонстрационный режим формы.

## Поведение

202 возвращается после сохранения заявки на диск. Уведомления отправляются раздельно на два адреса; временные ошибки SMTP повторяются с задержкой. Уже подтверждённый получатель повторно не уведомляется при обычном повторе. При аварии между приёмом SMTP и сохранением статуса возможно повторное письмо. SMTP acceptance не гарантирует попадания во «Входящие».

Есть проверка данных, согласия, origin, размера запроса, частоты запросов и idempotency UUID. Данные и SMTP credentials никогда не размещать в Git или публичной папке. Настроить резервирование, мониторинг ошибок `lead_*`, срок хранения заявок и очистку по принятой политике компании. Ограничение запросов хранится в памяти одного процесса.

## Приёмка перед включением

Отправить согласованную тестовую заявку через сайт; проверить оба ящика, очередь и отказ SMTP; проверить повтор запроса с тем же UUID; убедиться, что при ошибке поля сохраняются и экран благодарности не появляется. Настроить SPF/DKIM для домена отправителя по инструкции почтового провайдера. Секреты вводить в настройках хостинга, не в переписке.
