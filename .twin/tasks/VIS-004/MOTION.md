# VIS-004 — движение

Нативная прокрутка, без перехвата wheel/touch. Journey: 4 состояния, 1800px пути только при полном fit после fonts.ready; иначе ручной Grid/accordion. Четыре диапазона 0–.25/.25–.5/.5–.75/.75–1. Отдельная смена изображения opacity 500ms cubic-bezier(.22,1,.36,1); текст меняется целиком без наложения двух описаний. Клик, Space/Enter и arrows/Home/End для фокуса; обратный ход и re-entry определяются текущим расстоянием. Пауза фиксирует progress. Resize измеряет полезную высоту; короткое окно не уменьшает заголовок ради pin. Reduced motion: без pin и transforms, ручной выбор доступен. Каналы: четыре кликабельные карточки, активная впереди; заголовки остальных видимы. Качества: once-замена Эффектно → Эффективно. Cleanup observers/listeners/rAF на unmount. H02 — неподвижный фасад, отдельный parallax не заявлен.

Исправление после фактической прокрутки: запас для sticky — реальная height родителя (panelHeight +1800 +36), не padding-bottom. Padding давал пустой участок и не удерживал панель в containing block. При проверке измерить top панели32px в середине track и свободный выход в demo.
