# VIS-004 — фактическая проверка

Self-review, не независимая приёмка и не одобрение владельца.

Открыта реальная статическая сборка с production paths в облачном браузере. Пройдена обычная прямая/обратная прокрутка до финала. Проверены четыре режима Journey, ручной выбор в 1366×768, mobile390×844 и границы1099/1100 без горизонтального overflow. В середине desktop track top панели32px; выход в demo свободный. Открытие Integrations dialog, URL-state и Escape/back с возвратом фокуса работают. Четыре канала переключают описание и переднюю настоящую карточку.

Найдено и исправлено: отсутствовал передний фасад; заголовок пересекал фасад; белая подложка планировки; фиксация Journey на padding давала пустой участок; фиксированная мобильная высота пересекала текст/фото; модель качеств заходила под нижний тезис. Отклонён первый alpha-вырез планировки с дырами во внутреннем полу.

Оценка по наблюдениям, не сертификат WCAG: иерархия7.5, согласованность8, доступность6.5, удобство7.5, адаптив7.5, performance не измерена. Общий числовой PASS не вычисляется без измерения performance.

Остаётся отдельный финальный прогон reduced-motion и формального visual gate. Иллюстративные UI-сцены не становятся настоящим viewer. Приём заявок не подключён. Вердикт: рабочая примерка для просмотра, release gate не пройден.
