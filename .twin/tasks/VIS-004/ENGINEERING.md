## Графические заказы
H01 — новый master 16:9. Разрешён владельцем 28.10. Один исходный проход и одна адресная коррекция формата; реальные native dimensions фиксируются в production/manifest.json.
H02 — извлечён alpha-фасад на общем холсте 1672×941. Он продолжает фотографическую архитектуру поверх белой плоскости Journey. CSS убирает пустую левую часть слоя со случайным пиксельным мусором. H03 clean plate потребуется для независимого параллакса. В текущей статичной связке master и foreground остаются совмещены; дублирования движущегося здания нет. Декоративный параллакс отложен до отдельного набора слоёв; это явно открытое отличие от будущей полной motion-сцены, не новая «готовность».
L01–L04 — материалы / состав / разработка / проверка. 4 отдельных alpha-иллюстрации, без надписей. CSS слот 280×210, ratio 4:3, contain, общая камера/свет; native output измеряется. Полные PNG сохраняются, производные WebP служат доставке.
CH01/C01 — использовать утверждённые изображения каналов и всего проекта. Генераций 0. Оригиналы assets/approved/2026-10-27, веб-копии public/media/approved-20261027. Контрольные суммы и точное RGBA равенство в runtime-assets.json.

## Движение и адаптив
Статичная сцена обязательна до анимации. Hero остаётся стабильным фотографическим полем. Journey при ширине >=1100 и достаточной высоте получает native sticky: 4 hold-состояния в 1800px пути, переходы opacity/transform 500ms cubic-bezier(.22,1,.36,1). Высота измеряется после fonts.ready; при недостатке места обычный Grid и клики, без уменьшения шрифта. Wheel/touch не перехватываются. При re-entry/reverse прогресс определяется текущей прокруткой.
Каналы: клик выбирает карточку и её описание; соседние полосы остаются видны, z-order переключается без анимации layout. На mobile активная карточка в обычном потоке, все четыре переключателя доступны. Качества: once reveal, слово «Эффектно» сменяется на «Эффективно» по видимости. Reduced motion отключает pin/transform, содержание остаётся доступным.
Mobile: заголовок, спокойная фотография, затем Journey accordion с изображением прямо под активным текстом. Демо в одну колонку. Состав: модель и шесть групп. Запуск 1 колонка, tablet 2. Контакт в одну колонку. Никакого горизонтального скролла или скрытых focusable controls.

## Приёмка и ограничения
Проверить в браузере массу/интервалы/материал/текст каждого раздела и всю обычную прокрутку. Проверки сборки, JSON, hash и наличие картинки не дают visual PASS. При недоступном браузере self-review остаётся blocked и публикация прежнего /v2/ не выполняется в обход gate.
Реальный viewer и приём заявок не подключены: demo показывает пример, форма не отправляет данные. Коммерческие числа наследуются из текущего content, не превращаются в рыночную гарантию.
Сохранение: отдельная рабочая ветка work/vis004-execute-20261028, затем проверенная передача. V1 сохраняется. Полный scope — весь сайт, проверка hero/Journey не сокращает задачу.

Дополнительно подготовлен alpha-вырез планировки для графитовой сцены. Первый вариант отклонён: нарушена непрозрачность центрального пола. Адресная коррекция восстановила внутренние поверхности, оригинал сохранён. Используется только в V2 через необязательный planSrc. В V1 defaults не изменены.
