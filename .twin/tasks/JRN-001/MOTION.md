# Motion Journey
Один источник scroll-progress p∈[0,1], вычисленный из реальных top/bottom секции и sticky-окна. Стартовое инженерное значение track460svh, panel100svh. Оно не является эстетической приёмкой: после проверки читаемости скорректировать в контракте, не добавлять произвольные множители по разным компонентам. Не перехватывать wheel и не считать количество прокруток.

Паузы сцен: [0,.16], [.31,.445], [.595,.73], [.88,1]. Переходы: [.16,.31], [.445,.595], [.73,.88]. Нормализовать каждый переход в u∈[0,1]. На паузах все тексты устойчивы. Не превращать весь участок в непрерывный морфинг.

Каскад в пределах перехода:
- u0–.18: старые пояснения уходят через маску/opacity; убираются из доступного дерева после выхода.
- u.12–.68: раскрытие новой карточки, закрытие старой. Следующие строки сдвигаются в потоке. Для обратимости интерполировать высоту двух измеренных inner-областей; не переключать display в середине и не использовать auto как интерполируемое число. Переизмерить при resize/font load; на mobile допустимо grid0fr→1fr по клику с overflow hidden.
- u.20–.55: смена верхнего заголовка маской; старый и новый не читаются одновременно.
- u.28–.88: новое изображение проявляется поверх предыдущего, scale1.035→1, translateY16→0, clip-path/inset с сохранением геометрии. Предыдущее находится под новым без пустого кадра; не размывать текст интерфейса. После перехода остаётся один слой.
- u.65–1: пояснения новой карточки появляются последними.

Движение transform/opacity — по easing(.22,1,.36,1); геометрия раскрытия детерминирована тем же progress, не отдельным таймером. При reverse все части воспроизводятся назад. При повторном входе состояние вычисляется из scroll-position. Быстрый клик отменяет предыдущий переход и ведёт к выбранной сцене; не накапливать таймеры и scrollTo. Прямой переход к сцене не обязан проигрывать все промежуточные тексты.

Pin включать только после проверки, что max высота содержимого помещается в доступный viewport с отступами и header. Иначе обычный поток/switch. Resize сохраняет смысловую активную сцену и не ломает browser Back. Reduced-motion: мгновенное переключение, обычный поток без длинного pin; контент не скрыт. Клавиатура: Enter/Space на кнопке, понятный focus; не перехватывать естественную прокрутку.

Проверить остановки в .1/.25/.5/.75/.95, быстрый и медленный проход, вверх/вниз, повторный вход, клики1→4→2, загрузку по якорю, resize desktop→mobile, reduced-motion. Фиксировать реальный дефект и его исправление, а не только факт запуска анимации.
