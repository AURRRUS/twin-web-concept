## Общий переход hero → Journey
Один доступный исходный кадр; его нижний край раскрывается тонким бронзовым контуром по белому полю. Делать собственный компонент ArchitecturalTransition с SVG path/mask, задаваемым viewBox, размер высоты96pxdesktop/40pxmobile. Верхний рисунок может чуть заходить в следующий эпизод только в декоративной области. Не наклонять весь DOM, левую колонку или интерфейс; текст и actions на горизонтальной сетке. Не маскировать разрыв фото произвольной белой дымкой. Если нет фото для отдельного вертикального ракурса, использовать существующий кадр; не генерировать новый без необходимости. Нет искусственного 3D-подиума.

## Низкие окна
Не отключать весь scroll-рассказ только из-за малого fit. Сначала уменьшить декоративный переход и верхнюю паузу, использовать компактный dock H2 28/36, сохраняющий ту же формулировку и бронзовый фрагмент; body не уменьшать. Pin только при реальном fit всей панели; иначе на странице остаются четыре последовательные смысловые группы с соответствующими изображениями и мягкими reveal, работают также кнопки. Не прятать три режима и не превращать экран в статичную одиночную фотографию. Полезный скролл и trigger указаны в MOTION.

## Mobile/tablet
До1100 одноколоночная композиция; никаких многовидовых sticky-ловушек. H2, затем четыре accordion-группы. По умолчанию открыта первая. В открытой группе label → lead → body → изображение, затем следующие кнопки. Полное изображение с сохранением aspect ratio, отдельный доступный линк «Посмотреть Twin» при необходимости рассмотреть UI; не лупа с выдуманным управлением. Текст17/26, область нажатия44px+. Нет горизонтального overflow. Переключение не переносит фокус, раскрытое содержимое прокручивается естественно. Без JS показать все4 группы; reduced motion — мгновенное переключение без pin.
