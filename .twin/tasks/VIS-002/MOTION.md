# VIS-002 — scroll и управление
Это исполнимая web-спецификация. Без Canvas-видео и wheel-перехвата.
## Общие появления
Настоящий scroll и requestAnimationFrame, DOM semantic. Element reveal starts when its top reaches86% viewport, finishes near62%: opacity0→1, translateY18→0; группы title/body/media с задержками0/90/180ms, длительность560ms ease(.22,1,.36,1). Однократный вход для пояснительных секций, но не блокировать повторное управление Journey. SSR/no-JS всё видно; JS enhancement скрывает только готовые к reveal элементы, не целые секции до загрузки картинок.
## Связка hero → Journey
Панорама доступна с первого кадра; CTA не ждёт animation. Переход-сечение продолжает существующую фотографию без вращения; scroll интерполирует декоративный offset0→-24px, отключить на mobile/reduced motion. Никакого изображения в 0opacity на первом экране и белого светового overlay.
## Desktop Journey
При width>=1100 и panel fits(H-48) sticky top24. D=3*max(420,0.70*H)+max(240,0.35*H) px; общая высота sticky-контейнера = panelHeight+D. Один master progress p=clamp((scrollY-start)/D,0,1). Это путь скролла, не число wheel-событий. Остановки p:0,.3333,.6667,1. Паузы:0–.14; .27–.43; .56–.72; .86–1. Переходы:.14–.27;.43–.56;.72–.86.
Для каждого перехода q0..1:
- q0–.20: старый lead/body исчезают (маска + opacity), старое фото остаётся опорой.
- q.16–.55: height активной группы интерполируется от предыдущей к новой, следующие строки физически смещаются. Новая label получает бронзовую подложку. Высоты измерять по content, не max-height9999px.
- q.32–.67: новый lead появляется y12→0 под маской; body q.48–.80.
- q.58–1: новое изображение opacity0→1, y18→0, scale1.035→1; старое уходит .58–.82. Не показывать двойные строки, не масштабировать текст. Изображение абсолютное внутри aspect-ratio box; высота box стабильна.
Активное состояние для aria выбранное по середине перехода; в DOM одна доступная текстовая группа, декоративный outgoing слой aria-hidden. Не размножать все четыре полных текста для screen reader. Нет aria-live на каждый scrollframe.
Это каскад: label → lead → body → photo, не общий fade всех слоёв.
## Ручной выбор
Click/Enter/Space выбирает любой режим. В pinned-режиме перейти к соответствующей scroll-остановке duration640ms без отдельного конкурирующего driver; input wheel/touch/key прекращает автоматическое перемещение и отдаёт управление native scroll. Один source of truth p. В flow/mobile меняется state, animation height280ms/opacity, фото420ms; без изменения scrollY и focus. Стрелки/Home/End могут перемещать фокус по заголовкам; Tab естественный. На обратном scroll применять ту же функцию кадра; никаких once-флагов, сбрасывающих Journey. На повторном входе состояние определяется положением, а не только visited.
## Fit, resize и доступность
Измерять panel после fonts.ready и decode активного фото; ratio резервируется до загрузки. ResizeObserver пересчитывает размеры; сохраняется активный режим, не jump в первый. При недостатке высоты после компактного H2 использовать flow4группы как в VISUAL, с последовательными scroll-reveal всех режимов. Это полноценный альтернативный скролл, не потеря содержания. Mobile и reduced-motion без pin, без длинного пустого трека. С отключенным JS все4 текста и изображения доступны. Быстрый scroll допускает пропуск промежуточных кадров, финальный state корректен. Уход из секции отменяет RAF, наблюдатели cleanup. Видимость вкладки останавливает лишнюю работу.
