## Зависимости и ограничения
- Нет отдельного прозрачного фасадного слоя и проверенной скрытой грани здания для буквального физического разреза из AI-эскиза. Реализовано согласованное ступенчатое сечение исходной панорамы без новых архитектурных деталей. Для точного следующего прохода нужны alpha-маска балконов и реальное изображение грани в том же ракурсе/свете, не менее1920px. Это инженерное отличие от референса, не утверждение его буквального совпадения.
- Иллюстраций четырёх стадий строительства из AI-обзора в исходниках нет; использованы читаемые существующие этапы в HTML, новые изображения не генерировались.
- Viewer остаётся fixture; настоящий API и приём обращений не подключены. Форма не передаёт данные и не показывает ложный успех.3 месяца/5млн₽ перенесены из прежнего сайта как существующие ориентиры с индивидуальной оговоркой, без новой коммерческой проверки.
- Physical Safari/iOS/Android и специально ограниченная slow-network среда не проверялись. Chrome на GitHub runner — реальный браузер, но не эквивалент этим устройствам.
