# Подключение twin.bytalent.ru к Google Search Console и Яндекс Вебмастеру

Входить в кабинеты должен владелец аккаунтов компании. Токены подтверждения выдают сами сервисы — придумывать или
переиспользовать их нельзя. Сайт уже готов: главная открыта для индексации, `robots.txt` и `sitemap.xml` на месте.

## Как подтвердить владение (выбрать один способ на сервис)

| Способ | Кто делает | Что передать разработчику |
|---|---|---|
| TXT-запись в DNS | тот, у кого доступ к DNS bytalent.ru в Beget | ничего: запись добавляется в Beget |
| HTML-файл | владелец скачивает файл из кабинета | сам файл (`googleXXXX.html` / `yandex_XXXX.html`) |
| Мета-тег | владелец копирует тег из кабинета | строку тега целиком |

Файл или тег разработчик кладёт в ветку `release/twin-bytalent-domain` (файл — в корень, тег — в `<head>` корневого
`index.html`), коммитит, и через минуту они доступны на домене. После этого в кабинете нажать «Подтвердить».

TXT-запись для поддомена `twin` в Beget добавляется рядом с существующей A-записью `twin → 85.193.82.51`; A-запись не
трогать.

## Google Search Console — https://search.google.com/search-console

1. «Добавить ресурс».
   - Вариант «Доменный ресурс»: ввести `twin.bytalent.ru`, подтвердить только TXT-записью в DNS.
   - Вариант «Ресурс с префиксом в URL»: ввести `https://twin.bytalent.ru/`, подтвердить HTML-файлом или мета-тегом.
2. После подтверждения: «Файлы Sitemap» → `https://twin.bytalent.ru/sitemap.xml` → «Отправить».
3. «Проверка URL» → `https://twin.bytalent.ru/` → «Проверить страницу на сайте»: убедиться, что индексирование разрешено,
   canonical — `https://twin.bytalent.ru/`, страница отрисовывается. Затем «Запросить индексирование».
4. Через несколько дней — отчёт «Страницы»: ошибки сканирования и исключённые страницы.

## Яндекс Вебмастер — https://webmaster.yandex.ru/

1. «Добавить сайт» → `https://twin.bytalent.ru/`.
2. Подтвердить: мета-тег `yandex-verification`, HTML-файл или DNS-запись.
3. «Индексирование» → «Файлы Sitemap» → добавить `https://twin.bytalent.ru/sitemap.xml`.
4. «Инструменты» → «Проверка ответа сервера» для `https://twin.bytalent.ru/` (ожидается 200), «Анализ robots.txt».
5. «Индексирование» → «Переобход страниц» → `https://twin.bytalent.ru/`.

## Важно

- Отправка sitemap не гарантирует попадание в индекс; первые данные появляются через дни.
- В sitemap только главная. Юридические и резервные страницы закрыты `noindex` и в sitemap не входят.
- Старая копия на `aurrrus.github.io/twin-web-concept/` сейчас открыта для индексации на корне (старый V1) и
  `/journey-craft/`; см. RESULT.md.
