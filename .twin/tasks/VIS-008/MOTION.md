## 3. Точный scroll-контракт

H — высота viewport после загрузки шрифтов; `D=round(clamp(2800,4.2×H,4600))`px — дополнительный нативный путь внутри pin. Wrapper=`panelHeight+D`; `start=absoluteSectionTop−24`; `p=clamp((scrollY−start)/D,0,1)`.

Принятая фотографическая связка приходит к Journey обычной прокруткой. Pin начинается при достижении верхом полной панели y24. Предыдущая сцена не замедляется искусственным spacer и не обрезается новым sticky-слоем.

| Фаза | Интервал p | Действие и читаемое состояние |
|---|---|---|
| Вход / удержание1 | 0…1/21; затем1/21…1/4 | Локация уже видна; карточка/медиа мягко доходят до конечной позиции, затем полностью неподвижны |
| Смена1→2 / удержание2 | 1/4…1/4+1/21; затем…1/2 | Выбор и сравнение, затем самостоятельная пауза чтения |
| Смена2→3 / удержание3 | 1/2…1/2+1/21; затем…3/4 | План этажа, затем самостоятельная пауза чтения |
| Смена3→4 / удержание4 | 3/4…3/4+1/21; затем…1 | Пространство/виды по действующим текстам, затем полноценная финальная пауза |
| Выход | p=1, далее обычный scroll | Панель естественно уходит вверх; следующий существующий блок входит без перекрывающего fullscreen-overlay |

Квартал — примерно1.05H: reveal0.2H + hold0.85H при неклиппированной формуле. H900: D3780px, reveal180px, каждое удержание765px. H768: D3226px, reveal≈154px, hold≈653px. Условный шаг300px даёт около12.6/10.8 шагов на всю сцену; это **пример**, физический wheel/trackpad/swipe не имеют универсального размера. Три шага по300px не должны унести сцену за последний режим.

На hold ничего само не переключается; остановив scroll, пользователь читает сколько нужно. Никаких таймерных блокировок, preventDefault wheel/touchmove или обязательного ожидания секунд. Быстрый длинный fling/Home/End разрешён; все пропущенные состояния доступны прямыми кнопками. CSS scroll-snap в первом исполнении не добавлять: глобальная привязка может изменить уже принятый переход, а proximity всё равно не гарантирует просмотр каждого состояния.

## 4. Пластика, controls и обратный ход

Один чистый `frame(p)` вычисляет from/to/local/active. В transition `q=smoothstep(local)`. Общий H2 неподвижен. Картинка incoming раскрывается clip-path inset(0,0,(1−q)×100%,0) над полностью сохранённой outgoing; без zoom/перспективы/смещения UI. Детальная карточка: outgoing opacity1→0,Y0→−8px в первых40% перехода; incoming opacity0→1,Y12→0px в50…85%. В hold opacity1/transform:none. Высота aside зарезервирована, смещения соседних блоков отсутствуют. Активный control меняется один раз при local≥0.5, `aria-expanded`/медиа/текст синхронны.

Навигация ведёт в середину соответствующего hold: p=[0.14881,0.39881,0.64881,0.89881]. Click/Enter/Space запускают native smooth scroll; следующий wheel отменяет навигационное движение штатно. ArrowUp/Down,Home/End внутри группы перемещают focus, не блокируют выход Tab. В fallback кнопка переключает content без навязанной прокрутки страницы. При reverse тот же p даёт тот же кадр, без replay-флагов и лишних пауз. При resize сохранять ближайшую сцену; пересчитывать геометрию максимум один rAF, не запускать scrollTo из каждого ResizeObserver-кадра.

## 5. Адаптив и производительность

W<1100, H<680 или reduced-motion: D0, normal-flow accordion, полный текст и реальное изображение, controls≥44px. Reduced-motion также выключает clip/opacity/translate transitions. Fonts/images decode до начала pin; при ошибке изображения сохранить подпись/управление, не бесконечный spinner. Все тексты/links — DOM, не canvas. Scroll passive, один rAF, не setState на каждом пикселе: React только при смене active. Скрытая вкладка останавливает rAF, возврат вычисляет текущее p заново. Цель frame≤16.7ms — бюджет для измерения, не заявленный60FPS.
